# Kin iOS

Native iOS companion for remote control of the [Kin](https://github.com/vuuihc/openkin) agent daemon.

Start a task on your Mac, watch the transcript live, approve tool requests, answer questions, and cancel work — all from your iPhone.

## Quick start

```bash
# 1. On your Mac, start the Kin daemon
cd /path/to/kin
make build
./kin serve --lan      # local network
# or
./kin serve --tailscale  # over the internet via Tailscale

# 2. Build and run the iOS app
cd ios
xcodegen generate
open Kin.xcodeproj
# Select Kin iPhone 16 Pro simulator, press Run

# 3. Pair
# In the app, tap "Scan QR Code" and scan the QR printed by the daemon,
# or tap "Enter URL Manually" and paste the URL shown.
```

## Remote access options

| Method | Command | Access | Security |
|--------|---------|--------|----------|
| **LAN** | `./kin serve --lan` | Same WiFi | Bearer token + local network |
| **Tailscale** | `./kin serve --tailscale` | Anywhere (both devices need Tailscale) | End-to-end encrypted |
| **Funnel** | `./kin serve --tailscale --funnel` | Anywhere (public HTTPS) | TLS + Bearer token |
| **Cloudflare Tunnel** | `cloudflared tunnel --url http://localhost:7777` | Anywhere via your domain | TLS + Bearer token |

See [REMOTE_ACCESS.md](../../docs/REMOTE_ACCESS.md) for detailed setup guides.

## Requirements

- Xcode 26.6+ / Swift 6.3+
- iOS 17+ deployment target
- No third-party dependencies (Foundation, SwiftUI, Security only)

## Project structure

```

├── Kin/
│   ├── App/                ← App entry point + root model

│   │                          TaskDetail, NewTask, Settings

│   └── Resources/          ← Localizable.xcstrings (en + zh)
└── KinTests/               ← Unit tests (16 test cases)
```

## Development

```bash
# Generate Xcode project after adding/removing files
xcodegen generate

# Build for simulator
xcodebuild -project Kin.xcodeproj -scheme Kin \
  -destination 'platform=iOS Simulator,name=Kin iPhone 16 Pro' build

# Run tests
xcodebuild -project Kin.xcodeproj -scheme Kin \
  -destination 'platform=iOS Simulator,name=Kin iPhone 16 Pro' test

# Build for device (requires signing identity)
xcodebuild -project Kin.xcodeproj -scheme Kin \
  -destination 'generic/platform=iOS' \
  CODE_SIGN_IDENTITY="Apple Development" build
```

## Architecture

- **Single daemon projection** — The iOS app is a remote control surface for one Kin daemon. No local agent, no sync layer.
- **REST + WebSocket** — HTTP for snapshots and commands, WebSocket for live invalidation. Full reconciliation on reconnect and foreground.
- **@MainActor Reconciler** — Merges HTTP snapshots with WebSocket live updates. Events keyed by `(task_id, seq)` for idempotent merging.
- **Zero third-party dependencies** — `URLSession`, `URLSessionWebSocketTask`, `Security` framework only.
