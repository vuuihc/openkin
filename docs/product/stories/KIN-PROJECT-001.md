# KIN-PROJECT-001 · 一个项目的封面

状态：draft
优先级：P1
旅程：J4
归属面：`IA.md`「项目」行（对话列表里的项目标题 → `/projects/:id`）
面：Mac、手机

## 谁、什么时候、为什么

当我隔了几天回到一个项目（一个工作目录），我想先看清这里最近发生过什么、上次做到哪，然后从这段对话继续或从这里开一段新的，以便不用在列表里一段段翻找，也不用在脑子里记住进度。

## 现在

项目封面已经存在（`ProjectDetailPage.tsx`），但它没有一个故事：页面测试缺失（R0a 证据：`/projects` 没有直接页面测试），概览与对话两个 tab 的分工、概览里哪一块是「活的」、例行任务块归谁，都没有写下来。封面上的「新建对话」只带第一个 root；概览的 pulse 刷新失败时整页只剩骨架。

截图：`04-project-1280.png`、`20-project-1100.png`（手机没有项目页截图）。

## 范围

- 做：从列表的项目标题打开封面 → 看概览（最近活动、热力图、一句话摘要）→ 切到「对话」→ 继续一段对话或从这个项目新建 → 改项目的模式与一句话摘要 → 离开再回来。
- 不做：在封面上改名、置顶或归档项目（归 `KIN-MANAGE-001`，那是列表行的事）；diff 与改动详情（`KIN-RESULT-001`）；项目上的例行任务的新建与调度（`KIN-ROUTINE-001`；封面只显示归属与入口）；跨设备同步项目记录。

## 每一步的预期

### 1. 定义 / 打开：我要回到那个项目

| 项 | 预期 |
|---|---|
| 起点 | Mac 左栏或手机列表页，项目标题可见 |
| 动作 | 点项目标题（不是它前面的折叠箭头） |
| 立刻看到 | 打开 `/projects/:id`；页头是项目名、第一个 root 路径、模式；正文先出概览骨架，不整页空白 |
| 慢 / 空 / 失败 / 断线 | 项目记录已不存在时说「这个项目不在了」并给回列表；离线时显示上次缓存的名字与路径，概览区域说明「离线，显示上次结果」 |
| 键盘与焦点 | Mac：Tab 能到项目名与两个 tab，←/→ 换 tab；手机：返回箭头至少 44px |
| 离开再回来 | 回到同一个 tab、同一段滚动位置 |

### 2. 定位：先看这里最近发生了什么

| 项 | 预期 |
|---|---|
| 起点 | 项目封面，概览 tab |
| 动作 | 读概览，不点任何东西 |
| 立刻看到 | 最近活动（最后一次对话、最后一次提交）、两周热力图、一句话摘要；空项目写「这里还没有对话」而不是一排 0 |
| 慢 / 空 / 失败 / 断线 | 概览加载中出骨架；pulse 失败时其余区块照常显示，概览顶部给「概览暂时读不到」和刷新；断线时保留上次内容并标注时间 |
| 键盘与焦点 | Mac：刷新按钮可 Tab 到，Enter 触发；手机：热力图可横向滚动，不撑破页面 |
| 离开再回来 | 概览保持上次内容，不回到骨架 |

### 3. 准备 / 确认：找到要接的那段

| 项 | 预期 |
|---|---|
| 起点 | 项目封面 |
| 动作 | 切到「对话」tab |
| 立刻看到 | 这个项目的对话按最近活动排：原生对话与导入的 agent 会话同一行形；每行有标题、agent、相对时间、可操作的状态点 |
| 慢 / 空 / 失败 / 断线 | 加载中出骨架；没有对话时写「还没有对话」并给「从这里新建」；加载失败给原因和重试，不显示成空 |
| 键盘与焦点 | Mac：↑/↓ 换行，Enter 打开，Esc 回概览；手机：点一行进入，行高至少 44px |
| 离开再回来 | 停在「对话」tab（`?tab=chats`），滚动位置保留 |

### 4. 执行：继续，或从这里开一段新的

| 项 | 预期 |
|---|---|
| 起点 | 「对话」tab，或概览的「新建对话」 |
| 动作 | 点一行继续；或点「新建对话」 |
| 立刻看到 | 继续：打开那段对话，焦点在输入框；新建：打开 `/new`，设备与项目已填成本项目（root 作为 cwd） |
| 慢 / 空 / 失败 / 断线 | 对话已不在（被删除）时说明并留在封面；项目没有 root 时「新建对话」禁用并说明；离线时禁用新建，继续已有对话仍可读缓存 |
| 键盘与焦点 | Mac：Enter 打开选中行，⌘Enter 等同「新建对话」；手机：点按进入，返回回封面原位置 |
| 离开再回来 | 从对话返回，回到封面的同一 tab 与位置 |

### 5. 修改：这个项目是什么、在做什么

| 项 | 预期 |
|---|---|
| 起点 | 概览 tab |
| 动作 | 改模式（ship / learn / explore / maintain）；编辑一句话摘要并保存 |
| 立刻看到 | 模式保存后就地更新；摘要有「保存中 → 已保存」，冲突时显示对方版本而不是静默覆盖 |
| 慢 / 空 / 失败 / 断线 | 保存失败保留编辑内容并说明；离线时编辑禁用并说明；摘要是空时说「还没写，一句话说明这个项目在做什么」 |
| 键盘与焦点 | Mac：⌘Enter 保存，Esc 取消并还原；手机：保存按钮在编辑框下方，不被键盘遮住 |
| 离开再回来 | 已保存的值保留；未保存的草稿在离开时提示 |

### 6. 收尾：从这里离开

| 项 | 预期 |
|---|---|
| 起点 | 项目封面，任意 tab |
| 动作 | 返回列表，或切到另一个项目 |
| 立刻看到 | 列表仍在原来的搜索、过滤与折叠状态；不因打开过封面而重置 |
| 慢 / 空 / 失败 / 断线 | 无网络也能返回列表；封面内容只是不再刷新 |
| 键盘与焦点 | Mac：Esc / 返回回到列表且焦点在原来的项目标题；手机：返回箭头回到列表顶部那条 |
| 离开再回来 | 下一次打开同一项目回到上次的 tab |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 封面占右侧主区，页头一行放项目名、root、模式；两个 tab 在页头下方；概览是两列（左：摘要与最近活动，右：热力图与例行任务） | 窗口宽，一屏看清；两列让「发生了什么」和「最近在哪」并排 |
| 手机 | 单列，页头压成两行（项目名 / root + 模式）；两个 tab 变成页头下的分段控件；热力图与例行任务在卡片内横向滚动 | 一屏只能放一件事；分段控件比 tab 条更好点 |

## 设计

设计稿：`KIN-PROJECT-001.figma/frames/`（SVG 源帧）和 `KIN-PROJECT-001.review.html`（Figma 帧为主体，每屏六段用户流程）。

必须画到的状态：默认、空项目、加载、概览失败、断线、项目不存在、摘要编辑中、摘要冲突。

## Do not

- 不在封面上做改名、置顶、归档（列表行的事，归 `KIN-MANAGE-001`）。
- 不在封面上新建或编辑例行任务的调度（归 `KIN-ROUTINE-001`；封面只显示与跳转）。
- 不为封面另造一套对话行；复用列表的行形与状态点规则。
- 不改 `/projects/:id` 的路由或项目记录的字段。
- 不在没有 root 时让「新建对话」看起来可点。
