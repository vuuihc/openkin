冷启动基线：包内控制台先出，不等网络

Figma 帧

用户流程

  1. 起点手机上冷启动 App（上一次已连过 Hub），或系统回收后从后台回来；网络刚抖过。
  2. 动作点开 App，不点别处。
  3. 立刻看到随包控制台的列表壳立刻出现（设备 / 项目 / 行按上次的范围），底部四个入口在；顶部一行灰字「离线 · 本地版本 1.9.0 · 更新未核对」，没有转轮挡住内容。
  4. 慢 / 空 / 失败 / 断线账户还没答、Hub 慢、完全没网时：有缓存就显示上次的列表与位置，没有就显示空态 +「离线 · 正在用本地版本」；不白屏、不无限转轮；首次安装且没连过 Hub 时仍落在连接页（基线是控制台，不是已登录会话）。
  5. 键盘与焦点首帧焦点在主区标题，不自动弹键盘、不自动聚焦底栏；外接键盘 Tab 从内容开始。
  6. 离开再回来列表范围（搜索 / 状态 / 归档）、滚动位置、选中的设备按现有记忆恢复；切后台再回来不重新走开屏。
02 · 手机 · 390×844

后台核对与取回：状态只占一行

Figma 帧

用户流程

  1. 起点基线已渲染，顶部那行状态在；已保存 Hub 地址。
  2. 动作不点任何东西（App 在首帧之后自己开始）；想细看就点开状态行，这是可选的，不是必须。
  3. 立刻看到状态行写「本地版本 1.9.0 · 正在后台核对 2.0.0」，取回时变成「正在取回 2.0.0（x%）」；点开是一个只读小面板：当前版本、来源（本地 / Hub）、上次核对时间、Hub 版本与兼容结果。进度只在那一行，不遮挡内容、不占布局、不弹窗。
  4. 慢 / 空 / 失败 / 断线停住（观测到的那次是 20 秒没有新字节；有界阈值归 R-boot-guard）就放弃这次，状态行回「仍用本地版本 · 稍后再试」；Hub 500 同一句；完全没网就不发请求，写「离线 · 本地版本」；只取到一半时已取的文件不参与换入。核对没回来时面板写「还在核对」；读不到 Hub 版本时写「连不上 Hub，继续用本地版本」，不猜版本号、不显示 0。
  5. 键盘与焦点进度不是控件，不进 Tab 序、不抢焦点；状态行是按钮，Enter / Space 打开面板；Esc 关闭后焦点回状态行；读屏只在状态行变化时礼貌播报一次。
  6. 离开再回来切后台暂停、回来继续或重来；不因为切后台就换入半套。关闭面板不改变任何状态；核对完成后状态行就地更新，不弹 toast。

校验通过、整套换入，原处继续

Figma 帧

用户流程

  1. 起点整套文件已取回，尚未换入；App 正在做版本、兼容、字节三项校验。
  2. 动作下一次开屏；状态行里的「现在换」是可选操作，不是必须。

  4. 慢 / 空 / 失败 / 断线版本相同或更旧不换；控制台要求的最低 Hub API 高于 Hub 实际 → 判不兼容，永不换；文件缺失、长度或摘要不符、index 与入口对不上 → 判半套，永不换；任一项没有结论都按「不换」处理。切换中进程被杀 → 下次开屏仍打开上一份完整版本，不落在半套上。

04 · 手机 · 390×844

取不回：停住 / 500 / 断线，仍用本地版本

Figma 帧

用户流程

  1. 起点后台正在取回 / 校验，或刚刚失败（停住、500、断线、只取到一半）。
  2. 动作继续用控制台：翻列表、开对话、发消息；要重试时按状态行。
  3. 立刻看到所有前台操作不受影响；发消息不排在整套下载后面，后台不抢前台请求。状态行是一句「连不上 Hub · 仍用本地版本 1.9.0」+「重试」，列表一直可用，不转圈、不弹模态；半套或摘要不符不会被换入，也不会被当成「更新完成」。
  4. 慢 / 空 / 失败 / 断线停住 → 「更新没取完，仍用本地版本」+ 可重试；Hub 500 → 同一句；没网 → 「离线 · 本地版本」，网络回来可再试；半套 → 永不换入；每种只说一次，不重复弹。
  5. 键盘与焦点失败提示不是模态、不抢焦点；要重试时状态行是按钮，Enter 触发；焦点不因失败文字变化而移动。
  6. 离开再回来失败结论保留到下次核对；重试不改变当前控制台与位置。
05 · 手机 · 390×844

两侧不兼容：一个主行动，不转圈

Figma 帧

用户流程

  1. 起点App 与 Hub 的版本无法一起工作（App 太旧或 Hub 太旧）。
  2. 动作看状态行，或打开面板。
  3. 立刻看到当前控制台仍然打开并且能用；面板里只有一个主行动：App 太旧 →「这台 Hub 需要更新的 App」（App 1.9.0 · Hub 2.0.0）+ 更新 App；Hub 太旧 →「这台 Hub 需要更新」+ 去设置 / 复制地址；不同时给两个同等显眼的按钮，「稍后」不是同等按钮。
  4. 慢 / 空 / 失败 / 断线判断不了兼容性（Hub 不答、版本读不到）不算不兼容：继续用当前版本并写「无法确认」，不锁死，也不假装有结论。
  5. 键盘与焦点主行动可获得焦点；Esc 关闭面板回状态行；不自动跳设置。
  6. 离开再回来结论保留到下次核对；更新 App / Hub 后下一次开屏自动恢复；上一份完整版本仍在，可回退。
