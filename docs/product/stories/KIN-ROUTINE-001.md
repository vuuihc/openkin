# KIN-ROUTINE-001 · 让它按时跑

状态：approved
优先级：P1
旅程：J4
归属面：`IA.md`「例行任务」行（`/routines`）
面：Mac、手机

## 谁、什么时候、为什么

当有一件事我每天或每周都要交给 Kin 做（看一遍改动、整理一次笔记、跑一组检查），我想把它存成这台机器上的例行任务，到点自己跑、跑完告诉我，以便我不用每次重新写一遍提示词，也不用记得去做。

## 现在

例行任务属于机器而不是 Hub：cwd、agent、凭据和调度都在那台机器上（`IA.md`「例行任务」）。页面已有机器的选择、列表、新建 / 编辑、run-now、已读与运行记录。但首次打开会落在记住的机器上，即使它已经离线（R0a 截图时默认机器是 `<device-id>`，桌面报 `node is not connected: ios-…`，手机显示 `Still connecting`）；新建表单里的目录、agent、模型与权限与新建对话不是同一套写法；运行记录分页与未读计数没有页面测试。

截图：`10-routines-1280.png`、`23-routines-390.png`。

## 范围

- 做：打开 `/routines` → 落在在线的机器 → 看这台机器的例行任务与未读 → 新建或编辑（提示词、调度、目录、agent / 模型 / 权限、会话方式）→ 看下一次运行时间 → run now、已读、删除 → 看运行记录 → 离开再回来。
- 做：每条例行任务选会话方式。默认是「同一条会话持续」：所有运行接着同一段会话，上下文不断；也可以选「每次执行新建会话」：每一轮在那个项目里开一段新会话。两种方式都只影响会话落在哪里，不影响调度。
- 做：`/routines` 只保留运行记录（时间、结果、耗时、未读），不内嵌对话内容，也不放第二份对话列表；会话在它所属的项目里，用户回列表按项目找。
- 不做：跨机器的例行任务列表（一次只属于一台机器）；把例行任务同步到 Hub；在项目封面上新建调度（`KIN-PROJECT-001` 只显示归属）；通知的送达与落点（`KIN-NOTIFY-001`）；在 `/routines` 里读或管理会话本身。

## 每一步的预期

### 1. 定义 / 打开：我要管哪台机器的例行任务

| 项 | 预期 |
|---|---|
| 起点 | Mac 左栏底部或手机 K 面板的「例行任务」 |
| 动作 | 打开 `/routines` |
| 立刻看到 | 页面标题与一行机器选择；默认落在第一台在线的非本机机器（没有就落在本机），列表与未读跟着它 |
| 慢 / 空 / 失败 / 断线 | 机器列表加载中显示「正在找机器…」；记住的机器已离线时仍显示它但标「离线」并给一台在线的可切换，不静默换机器；机器读失败时保留已存选择并说明 |
| 键盘与焦点 | Mac：Tab 到机器选择与「新建」，↑/↓ 换机器；手机：机器选择是底部面板 |
| 离开再回来 | 仍停在上次的机器，除非它已离线且用户换过 |

### 2. 定位：这台机器上有哪些例行任务

| 项 | 预期 |
|---|---|
| 起点 | `/routines`，机器已定 |
| 动作 | 看列表与未读 |
| 立刻看到 | 每条显示标题、下一次运行、上一次结果（成功 / 失败 / 等待批准）、未读标记；顶部「全部标为已读」 |
| 慢 / 空 / 失败 / 断线 | 加载中出骨架；这台机器没有例行任务时写「这台机器还没有例行任务」并给新建；读失败给原因与重试；离线时禁用新建与 run-now 并说明 |
| 键盘与焦点 | Mac：↑/↓ 换条，Enter 展开运行记录；手机：一条一张卡，点按区至少 44px |
| 离开再回来 | 列表滚动位置与展开的那一条保留 |

### 3. 准备：写清要它做什么、什么时候做

| 项 | 预期 |
|---|---|
| 起点 | 列表，点「新建」或某一条的「编辑」 |
| 动作 | 写标题与提示词，选调度（每小时 / 每天 / 每周 / 自定义），选目录、agent、模型、权限与会话方式 |
| 立刻看到 | 表单就地展开；目录来自这台机器；agent / 模型 / 权限与新建对话同一套选择器与文案；调度旁显示「下一次：<本地时间>」；会话方式默认「同一条会话持续」，可切「每次执行新建会话」 |
| 慢 / 空 / 失败 / 断线 | 目录或模型加载失败时给重试，不清空已填；调度非法（过去时间、空规则）时就地说原因并挡住保存；离线时表单只读并说明 |
| 键盘与焦点 | Mac：Esc 关闭表单并还焦点给入口；手机：选择器是底部面板，面板不撑高表单 |
| 离开再回来 | 未保存的表单关闭前提示；已保存的值保留 |

### 4. 确认：什么时候会跑

| 项 | 预期 |
|---|---|
| 起点 | 新建 / 编辑表单已填完 |
| 动作 | 读「下一次」并保存 |
| 立刻看到 | 保存后这一条出现在列表，带下一次时间；时区说明用本机时区 |
| 慢 / 空 / 失败 / 断线 | 保存失败留在表单并说明；调度被服务端拒绝时显示原因，不假装保存成功 |
| 键盘与焦点 | Mac：⌘Enter 保存；手机：保存按钮不被键盘遮住 |
| 离开再回来 | 重新打开这一条，字段与调度一致 |

### 5. 执行 / 监控：到点自己跑，跑完能看见

| 项 | 预期 |
|---|---|
| 起点 | 列表，某一条到点或手动 run-now |
| 动作 | 等它跑，或点「立即运行」 |
| 立刻看到 | 这一条显示「运行中」；跑完显示结果与时间，未读加一；失败显示原因与重试；会话在项目里——默认接着同一条会话，选了「每次执行新建会话」则这一轮开一段新的 |
| 慢 / 空 / 失败 / 断线 | run-now 失败时说明是机器离线还是任务被拒；跑的过程中离开页面，回来仍能看到「运行中」或结果；通知没送到不影响这里的结果 |
| 键盘与焦点 | Mac：run-now 在行尾菜单里，Esc 关闭菜单；手机：动作面板选完自动关闭 |
| 离开再回来 | 结果与未读保留；运行记录按页加载，旧的接在后面；这一页不缓存对话内容 |

### 6. 收尾：读过了，运行记录还在

| 项 | 预期 |
|---|---|
| 起点 | 列表，有未读 |
| 动作 | 读结果，标为已读（单条或全部） |
| 立刻看到 | 未读标记消失；侧栏角标跟着减；运行记录里这一轮可回看，会话在它所属的项目里 |
| 慢 / 空 / 失败 / 断线 | 标记失败时保留未读并说明；运行记录加载失败给重试；断线时只读 |
| 键盘与焦点 | Mac：读到的那一条保持焦点；手机：标记后回到列表同一位置 |
| 离开再回来 | 已读状态还在；未读角标与列表一致 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 单列宽页：机器选择一行，列表在左、选中一条的运行记录在右；新建表单在列表上方就地展开 | 窗口宽，列表与运行记录可以并排；表单不跳页 |
| 手机 | 单列：机器选择 → 列表 → 点开运行记录；新建是全屏表单，选择器是底部面板 | 一屏只能放一件事；全屏表单才放得下调度与选择器 |

## 设计

设计稿：`KIN-ROUTINE-001.figma/frames/`（SVG 源帧）和 `KIN-ROUTINE-001.review.html`（Figma 帧为主体，每屏六段用户流程）。

必须画到的状态：默认、加载、空、机器离线、运行中、成功、失败、等待批准、未读、调度非法、会话方式（同一条持续 / 每次新建）。

## Do not

- 不把例行任务做成 Hub 侧的资源；调度与执行只属于选中的机器。
- 不静默把用户记住的机器换成另一台；离线就标离线。
- 不新增通知通道或改通知文案（`KIN-NOTIFY-001`）。
- 不在项目封面上新建调度（`KIN-PROJECT-001`）。
- 不在 `/routines` 内嵌、保留或复制会话；这一页只放运行记录，会话在项目里（2026-11-11 签字）。
- 不把「每次执行新建会话」做成默认；默认是同一条会话持续（2026-11-11 签字）。
- 不为这一页另造 agent / 模型 / 目录选择器；复用新建对话的那一套。
