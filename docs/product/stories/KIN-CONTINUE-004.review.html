01 · 手机 · 390×844

默认列表：设备按最近活动排、每设备新建

Figma 帧

用户流程

  1. 起点在手机上打开 Kin，落到对话列表；已有两台以上设备、每台都有几段对话。
  2. 动作不点任何东西，先扫设备标题；要新建时点那台设备标题右侧的加号。
  3. 立刻看到最近有活动的机器在最上面（示例：机器 A 1 小时前 → 本机 3 天前）；每台设备都有一个 44px 的次级新建；右上角是放大镜；头部「新建」还在。
  4. 慢 / 空 / 失败 / 断线首次加载先出设备标题骨架；读失败保留头部与放大镜并给重试；断线时顶部横幅、已加载分组不清空；一台设备都没有就说「还没有连接设备」并指向 Agent 运维。
  5. 键盘与焦点不自动弹键盘；Tab 顺序是头部新建 → 放大镜 → 各设备新建 → 项目箭头 → 行；焦点环用 focus-ring token；设备标题本身不是停点。
  6. 离开再回来设备顺序与滚动位置保留；重连后活动时间会刷新，但保持当前滚动锚点，不把人甩回顶部。
02 · 手机 · 390×844

空列表：入口一个都不少

Figma 帧

用户流程

  1. 起点刚连上设备、或所有对话都被归档/删除后的手机列表。
  2. 动作看空态；点头部「新建」，或点某台设备旁的新建。
  3. 立刻看到「还没有对话」+ 一句指路；头部新建仍在；已连接设备仍逐台列出，每台都写「还没有对话 · 只能新建」，没有折叠箭头。
  4. 慢 / 空 / 失败 / 断线加载中不显示「还没有对话」；读失败给重试而不是空态；离线设备仍在列表里，新建禁用并写「离线，连上后可在本机新建」；断线不清空入口。
  5. 键盘与焦点空态不是可聚焦控件；Tab 从头部新建开始，依次到每台设备的新建；禁用按钮可被读屏读到原因，但 Tab 跳过。
  6. 离开再回来从任一新建进入再关闭，回到这页空态；搜索词与滚动不发生多余变化。
03 · 手机 · 390×844

离线设备：锁新建，不锁历史

Figma 帧

用户流程

  1. 起点列表里一台最近用过、但现在离线的设备。
  2. 动作点它的新建，或点开它已有的对话。
  3. 立刻看到新建是灰的、不可点，紧挨着写明「离线，连上后可在本机新建」；已有对话仍可打开，行尾标「历史只读」；它仍按最近活动排在原位置。
  4. 慢 / 空 / 失败 / 断线设备从在线变离线时按钮就地变灰并出现原因，不弹窗；重连后自动恢复可点；设备被吊销后草稿页按 START-001 回本机并保留提示词。
  5. 键盘与焦点禁用按钮用 aria-disabled，原因在可达文本里、不靠 title；Tab 跳过它，但读屏浏览能听到原因；相邻的在线设备新建仍可 Tab 到。
  6. 离开再回来打开离线对话再返回，列表顺序与滚动不变；设备重连后顺序按新活动时间更新，当前行不跳走。
04 · 手机 · 390×844

搜索展开：还是同一个 SessionsSearch

Figma 帧

用户流程

  1. 起点默认列表，放大镜安静地待在右上角；地址栏没有 ?search=。
  2. 动作点放大镜，输入「发布」；然后点清除，或按 Esc。
  3. 立刻看到标题下展开原来的 SessionsSearch，焦点在输入框；列表即时过滤，地址栏变成 ?search=发布；放大镜显示激活态；清除只清词，不收起。
  4. 慢 / 空 / 失败 / 断线没有匹配时说「没有匹配的对话」并给「清除搜索」；搜索是本机过滤，不发起网络请求，断线不影响；带 ?search= 冷启动时字段直接展开。
  5. 键盘与焦点放大镜 44px、带 aria-expanded；展开后 Tab 进入输入框；Esc 有词时先清词，无词时才收起并把焦点还给放大镜。有词时不允许收成一个看不见的过滤条件。
  6. 离开再回来刷新、从对话返回、或从底部别的入口回来，搜索词与展开态都保留；点 × 清空后列表恢复全量，放大镜才可收起。

已定：每台设备标题旁加次级新建；离线禁用并就地写原因；没有会话的设备也显示，只能新建，不展开假项目。

代价：设备标题行更满，列表首屏少一点留给对话；换来不用先进新建页再改机器。

D4 搜索形态

已定：收成右上放大镜，点开仍是同一个 SessionsSearch，仍写 ?search=；有搜索词时不允许藏起来。

代价：搜索多一次点击；换来列表第一屏还给对话，且不新增第二个搜索控件。
