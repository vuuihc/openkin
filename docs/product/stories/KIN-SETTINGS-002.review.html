别的条
  • 为什么单独一条：升级的是桌面壳（Electron app），不是控制台、不是 daemon、不是 Hub——三者的更新通道各不相同，塞在一起必然漏一个。
  • 为什么不并进相邻故事：KIN-SETTINGS-001 是控制台里的运行默认值；这条是托盘里的壳版本，面不同、动作不同。
  • 设备只是差异：手机没有此面（PWA 由 Hub 重新部署自然更新），写在故事「各面差异」，不按设备拆故事。
  • 不在这一条：自动静默升级（app 未签名，macOS 不允许，见 D1）；Windows/Linux 桌面壳（无构建配置，等真实需求）；node CLI 的升级（install-node-service.sh 的通道）；「有新版」主动推送（先做拉取式）。
  • 大小：2 屏；一次交付；声明的面（Mac）成立。

现在

  • 升级 = 打开 GitHub Releases、肉眼找架构、下载 119MB、拖文件夹、重开。
  • 不知道自己跑的什么版本（dmg 里是 0.0.0-dev）。
  • Release 流水线只发 CLI 二进制，没有 dmg。

之后

  • 托盘常驻版本行；「检查更新…」一键查 GitHub。
  • 发现新版 → 菜单下载 → 通知弹出 → 点开 dmg 拖装。
  • 打 tag 的 release 自动产出 dmg（arm64）+ 校验和。

界面与用户流程

每一屏先看 Figma 帧，再读下面六段流程。托盘是系统菜单，帧为菜单形态线框。

01 · Mac · 托盘菜单 02 · Mac · 更新状态板
01 · Mac · 托盘菜单

版本行 + 检查更新（默认态）

Figma 帧

用户流程

  1. 起点菜单栏任意时刻；点托盘图标弹出此菜单。
  2. 动作看版本行确认当前版本；点「检查更新…」。
  3. 立刻看到菜单项变「正在检查…」灰掉；GitHub 返回后菜单刷新为新状态（见状态板）。
  4. 慢 / 空 / 失败 / 断线超时（10s）→ 菜单恢复 + 通知「检查失败：无法连接 GitHub」；无 mac 资产 → 通知「这个版本没有 Mac 安装包」；开发构建 → 通知「开发构建不检查更新」。
  5. 键盘与焦点系统托盘菜单，方向键导航；新组插在 Launch at Login 之前，不改变原有项的顺序。
  6. 离开再回来版本行是打包时常量，重开一致；检查进行中关菜单，结果以通知送达。
02 · Mac · 更新状态板

九个状态一板看全

Figma 帧

用户流程

  1. 起点「检查更新…」已点，GitHub 已答。
  2. 动作发现新版 → 点「下载 0.4.0…」；下载完点通知（或菜单「安装 0.4.0（已下载）」）。
  3. 立刻看到下载中显示百分比（按字节）；完成后点安装 → Finder 打开 dmg + 系统确认「要退出以安装吗？退出并打开 / 稍后」；确认退出后把 Kin.app 拖入 Applications 覆盖，重开即新版。
  4. 慢 / 空 / 失败 / 断线下载中断 → 菜单恢复「下载…」可重点（半成品写在 .part，绝不挂载）；磁盘满 → 通知「下载失败」；open 失败（dmg 损坏）→ 通知「安装包打不开，请手动下载」；检查失败 → 失败原因行 + 「重试检查…」。
  5. 键盘与焦点全系统托盘菜单 + 系统通知；点通知即动作（下载中→无操作，已下载→安装）。
  6. 离开再回来点「稍后」→ 菜单变「打开已下载的 0.4.0」（再点直接重开 dmg，不再追问）+「删除已下载的安装包」；重启后系统清理临时目录，自动回默认态。

要你拍板的

每条都写推荐和代价；只回不同意的编号。

D1 升级的终点是「挂载 dmg + 拖装」，不是静默自替换

已定：app 未签名（electron-builder identity: null），macOS 不允许运行中的进程替换自己；假装能静默升级是骗人。点「安装」= open dmg → Finder 拖装 → 重开。

代价：多一次拖拽。换来的是对签名状态诚实；将来签名后可升级为 electron-updater 全自动。

D2 更新检查只在用户点击时发生（第一版不做后台轮询/主动通知）

推荐：拉取式。托盘点一次查一次，不自动轮询、不弹「有新版」。

代价：新版本不会主动找你。换来的是零打扰、零后台上行流量；等真实使用后觉得需要再加轮询（另开故事）。

D3 只发 arm64 dmg；Intel Mac 暂不打包

推荐：arm64 先行（现在的 Mac 都在 arm64 上），CI 加 x64 会把 release 时间翻倍且没人用。

代价：Intel Mac 用户第一版下载不到 dmg（CLI 二进制仍有 darwin-amd64 兜底）。有真实需求再加一行 arch。
