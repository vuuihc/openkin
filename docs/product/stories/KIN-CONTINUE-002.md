# KIN-CONTINUE-002 · 手机只留一个导航面：列表页就是侧栏

状态：approved
签字：2026-11-12 用户。D1 改为「归档保留，导入放到 Agent 运维」；D2、D3、D4 同意。
优先级：P0
旅程：J1、J2
归属面：`IA.md`「手机对话列表」
面：Mac、手机

## 谁、什么时候、为什么

当我拿起手机，想接着问昨天那段对话，或去例行任务、Agent 运维、设置，我想在同一个列表页里看到所有对话、也能去所有地方，以便不用先点左上角打开另一个面板，再从那里绕回列表。

## 现在

手机上同时有三个导航面：页面列表、左上角 K 抽屉、底部 dock。K 抽屉里又是一份带搜索的列表和一组入口；从一段对话回到列表，要先侧滑开抽屉、点例行任务、再点 dock「会话」。同一条左缘右滑被绑成「开抽屉」，不是「返回」。

IA 2026-10-30 的 D3 把「K 面板只留入口」当成合并，但列表页和抽屉仍是两个面。2026-11-12 用户改选 B：手机只留一个面，列表页就是侧栏。这条取代 IA D3 与 `NAVIGATION.md` D1/R1 的手机部分；签字后同步改这两处。

## 范围

- 做：手机上一个导航面——列表页带搜索、列表和底部入口（归档、例行任务、Agent 运维、设置）；导入收进 Agent 运维页；删掉手机抽屉与 dock；对话、新建、目的地都从列表页推出，返回一步回列表；深链冷启动合成列表父级；键盘焦点、44px 触达；加载、空、读失败、断线各自有文字与下一步。
- 不做：Mac 布局（保持左栏）；运行设置面板形态（沿用 CONTINUE-001）；列表行、搜索、分组的内部逻辑（沿用 CONTINUE-001 与 R0b-2d）；新建页表单（START-001）；目的地页面自身内容（ROUTINE / AGENTS / SETTINGS）；通知（NOTIFY）。

## 每一步的预期

### 1. 打开：冷启动落到唯一的列表页

| 项 | 预期 |
|---|---|
| 起点 | 手机上从桌面图标或浏览器打开 Kin，没有指定深链 |
| 动作 | 打开应用，不点任何东西 |
| 立刻看到 | 一页列表：顶部搜索框，中间 设备 → 项目 → 对话，底部一行入口（归档、例行任务、Agent 运维、设置）；右下是新建按钮；没有抽屉、没有 dock |
| 慢 / 空 / 失败 / 断线 | 列表先出骨架；一条对话都没有时说「还没有对话」并指到新建；列表读失败时给重试，底部入口仍在；断线时顶部一条「连接断开，正在重试」，已加载内容不清空 |
| 键盘与焦点 | 不自动弹键盘；外接键盘 Tab 从搜索框开始，依次到列表行、底部入口、新建按钮，焦点环可见 |
| 离开再回来 | 搜索词、折叠状态、滚动位置保留；再次打开落回同一页 |

### 2. 打开一段对话，再返回

| 项 | 预期 |
|---|---|
| 起点 | 列表页，某一行是昨天没问完的对话 |
| 动作 | 点这一行；看完后点页头返回，或从屏幕左缘右滑，或按系统返回 |
| 立刻看到 | 对话整页推出，页头有返回；列表留在下面，不重新加载；返回一步就回到列表，焦点落回刚才那一行 |
| 慢 / 空 / 失败 / 断线 | 历史加载中先出对话骨架，返回随时可用；加载失败给重试；断线时横幅在页头下方，输入框保留草稿 |
| 键盘与焦点 | 打开后焦点在输入框，可直接打字；返回后焦点回到行，不回到搜索框 |
| 离开再回来 | 列表的搜索词与滚动位置不变；对话的滚动位置不变 |

### 3. 去别处：底部入口 → 目的地 → 返回

| 项 | 预期 |
|---|---|
| 起点 | 列表页，底部入口一行：归档、例行任务、Agent 运维、设置 |
| 动作 | 点归档（同一份列表切到已归档范围）；点例行任务、Agent 运维或设置；要导入会话时进 Agent 运维，用页头的导入；办完事后返回 |
| 立刻看到 | 归档在原页加一条「已归档 · 清除」的范围条，不换页；例行任务、Agent 运维、设置整页推出，页头有返回；返回一步回列表，焦点回到刚才那个入口；列表页没有导入入口，导入只在 Agent 运维页里 |
| 慢 / 空 / 失败 / 断线 | 目的地自己的加载、空、失败、断线照旧；目的地读失败时返回仍可用，列表不被替换；断线时底部入口仍可点开本机设置 |
| 键盘与焦点 | Tab 能到每个入口，Enter 打开；返回后焦点回到入口；设置里的 Esc 只关设置，不退出应用 |
| 离开再回来 | 在目的地里改过的内容保留；回到列表时列表的搜索与滚动位置不变；归档范围离开再回来仍是归档，直到点「清除」 |

### 4. 深链与返回：冷启动也能回到列表

| 项 | 预期 |
|---|---|
| 起点 | 从通知、聊天或浏览器直接打开 `/tasks/:id`、`/routines`、`/agents`、`/settings` 或归档 |
| 动作 | 打开后点返回，或左缘右滑，或系统返回 |
| 立刻看到 | 目的地面整页打开；返回落到列表页，而不是无路可走或跳出应用；列表是合成的父级，仍可正常滚动和搜索 |
| 慢 / 空 / 失败 / 断线 | 父列表加载中先出骨架，返回仍可用；列表读失败时父级显示重试，不把用户困在目的地；断线时返回不需要网络 |
| 键盘与焦点 | 深链打开后焦点在目的地面；返回后焦点在列表页头或上次停留的行 |
| 离开再回来 | 再次打开同一深链仍落在同一面；列表状态按上次保留 |

### 5. 新建：从列表页开始，再回到列表页

| 项 | 预期 |
|---|---|
| 起点 | 列表页右下角的新建按钮 |
| 动作 | 点新建，写提示词，开始；或点关闭 |
| 立刻看到 | 新建页整页推出，页头是关闭；开始后进入对话页，返回落到列表；关闭直接回列表，不留下第二层 |
| 慢 / 空 / 失败 / 断线 | 空内容、机器离线、没有可用 agent、断线时「开始」禁用并就地说明；创建失败留在新建页，提示词不丢；草稿在离开后仍保留 |
| 键盘与焦点 | 关闭后焦点回到新建按钮；开始后焦点在对话输入框；外接键盘 ⌘Enter 开始 |
| 离开再回来 | 草稿、设备、项目、模型与权限保留；新建页不留在历史里 |

### 6. 状态：空、加载、读失败、断线

| 项 | 预期 |
|---|---|
| 起点 | 列表页，数据还没到、没有数据、读失败或断线 |
| 动作 | 等、重试、或直接点底部入口 |
| 立刻看到 | 每种状态一句话与一个下一步；骨架、空态、失败态都保留页头搜索和底部入口；断线横幅只在真正断开后出现 |
| 慢 / 空 / 失败 / 断线 | 加载中不显示「没有对话」；空态指向新建；读失败给「重试」并保留已加载内容；断线时不清空列表，重连后自动刷新 |
| 键盘与焦点 | 重试按钮可 Tab 到；失败不抢焦点；断线横幅用 role=status，不打断阅读 |
| 离开再回来 | 重试后保留搜索与滚动位置；断线恢复后回到同一页同一位置 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 不变：左边一列是唯一的列表（设备 → 项目 → 对话），底部一行图标入口，主区是对话；没有手机抽屉与 dock | 窗口宽，列表和对话并排；Mac 的一列本来就是「一个面」 |
| 手机 | 列表页是唯一的导航面：顶部搜索，中间列表，底部四个图标入口，右下新建；对话、新建、目的地都是推出的整页，返回一步回列表 | 一屏只能放一件事；把入口并进列表页，才不会出现第二个导航面 |
| 两面 | 同一份列表、同一组目的地、同一套返回规则；宽度只决定壳的形态 | 两套实现会漂移，过去的五步路径就是这么长出来的 |

## 设计

设计稿：`KIN-CONTINUE-002.figma/frames/`（SVG 源帧）和 `KIN-CONTINUE-002.review.html`（Figma 帧为主体，每屏六段用户流程）。

必须画到的状态：默认、空、加载、读失败、断线、对话加载中、目的地离线、草稿返回。

## Do not

- 手机上不许再有抽屉、抽屉触发器、侧滑开抽屉或 dock。
- 不许保留任何第二份对话列表或第二个列表搜索框。
- 不许把例行任务、Agent 运维、设置做成需要展开的菜单或 sheet——它们是目的地。导入是 Agent 运维页里的动作，列表页不再有导入入口；归档是同一份列表的范围，不换页。
- 不许在列表读失败或断线时藏起底部入口。
- 不许把目的地做成必须先回列表再点的二级菜单。
- 不许改 Mac 布局、运行设置面板、接口、存储键或新增依赖。
- 单设备也不许隐藏设备名。
- 切换对话或目的地时不许整页变白屏或整页骨架。
