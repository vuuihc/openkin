现在 → 之后

现在（A）

  • 手机同时有三个导航面：页面列表、左上角 K 抽屉、底部 dock。
  • K 抽屉里又是一份带搜索的列表和一组入口；列表页是第二份。
  • 从一段对话回到列表：侧滑开抽屉 → 点例行任务 → 点 dock「会话」，五步。
  • 左缘右滑被绑成「开抽屉」，不是「返回」。

之后（B）

  • 手机只有一页：顶部搜索、中间列表、底部五个入口、右下新建；没有抽屉、没有 dock。
  • 归档是同一份列表的范围条；导入是选 agent 的动作菜单；例行任务、Agent 运维、设置整页推出。
  • 对话、新建、目的地都从列表页推出；返回一步回列表，焦点回到刚才那一行或那个入口。
  • 深链冷启动合成列表父级；左缘右滑、系统返回、页头返回是同一个动作。

01 · 手机 · 390×844

手机 · 列表页就是唯一的导航面

Figma 帧

用户流程

  1. 起点手机上打开 Kin；直接落在列表页：顶部搜索，中间 设备 → 项目 → 对话，底部五个入口，右下新建。没有 K，也没有 dock。
  2. 动作点搜索框过滤；滚动列表；点项目标题折叠；点一行打开对话；或点底部任一入口。
  3. 立刻看到设备名一直显示；项目是分组标题，对话是行；底部入口一行始终在，新建按钮在右下。
  4. 慢 / 空 / 失败 / 断线加载先出骨架；空说「还没有对话」并指向新建；读失败给「重试」；断线时顶部一条「连接断开，正在重试」，列表与入口都保留。
  5. 键盘与焦点不自动弹键盘；外接键盘 Tab 依次到搜索、列表行、底部入口、新建；焦点环可见。
  6. 离开再回来搜索词、折叠、滚动位置都保留；再次打开仍落回这一页。
02 · 手机 · 390×844

手机 · 对话页与一步返回

Figma 帧

用户流程

  1. 起点列表里的一行；点开，对话整页推出，页头有返回。
  2. 动作读消息；在输入框写下一句；点页头返回、按系统返回，或从屏幕左缘右滑。
  3. 立刻看到对话和输入框；列表留在下一层不重新加载；返回一步就回到列表，焦点回到刚才那一行。
  4. 慢 / 空 / 失败 / 断线历史加载先出对话骨架，返回随时可用；加载失败给重试；断线横幅在页头下方，草稿保留。
  5. 键盘与焦点打开后焦点在输入框，可直接打字；返回后焦点回到行，不跳到搜索框。
  6. 离开再回来对话的滚动位置不变；列表的搜索与滚动位置也不变。
03 · 手机 · 状态板 800×900

底部入口的形态：归档与导入不换页，其余整页推出

Figma 板

用户流程

  1. 起点列表页底部一行五个入口：归档、导入、例行任务、Agent 运维、设置。
  2. 动作点归档；点导入并选一个 agent；点例行任务、Agent 运维或设置；办完事后返回。
  3. 立刻看到归档在原页加一条「已归档 · 清除」的范围条；导入在原页弹一个选 agent 的小菜单；其余三个整页推出，页头有返回。
  4. 慢 / 空 / 失败 / 断线目的地自己的加载、空、失败、断线照旧；目的地读失败时返回仍可用，列表不被替换；断线时底部入口仍可点开本机设置。
  5. 键盘与焦点Tab 能到每个入口，Enter 打开；返回后焦点回到入口；设置里的 Esc 只关设置。
  6. 离开再回来目的地里改过的内容保留；回到列表时搜索与滚动位置不变；归档范围离开再回来仍是归档，直到点「清除」。

Mac 回归：左栏就是那一个面

手机改成 B 之后，Mac 不重画。这张帧用来确认两端仍是「一个列表、一个搜索、一组入口」，只是形态不同。

用户流程

  1. 起点Mac 1100 宽，左栏是唯一的列表，主区是对话或新建页。
  2. 动作在左栏搜索、点行；在主区读和写；返回时点列表行或按 Esc。
  3. 立刻看到左栏列表与底部图标；主区对话；没有手机抽屉、没有 dock、没有第二个搜索框。
  4. 慢 / 空 / 失败 / 断线沿用现在的状态与文案；这条不改 Mac 的加载、空、失败、断线。
  5. 键盘与焦点沿用左栏搜索与 ⌘K；这条不改 Mac 的焦点顺序。
  6. 离开再回来沿用现在的保留规则；这条不改 Mac 的状态。

要你拍板的

D0、D4 已定；D1–D3 是这次要确认的。每条都有推荐和代价，页尾有回复模板。

D0 手机的形状：A 还是 B

已定（2026-11-12）：B。手机只留一个导航面，列表页就是侧栏；不再有 K 抽屉和 dock。

代价：IA D3 与 NAVIGATION D1 签的是 A，这条要改签这两处；换来的是从对话回列表从五步变成一步。

D1 底部放哪五个入口

推荐：归档、导入、例行任务、Agent 运维、设置，和 Mac 底部一行同一组、同一顺序；每个至少 44px 高，图标 + 小字标签。

代价：390 宽下五个入口比较紧，标签只能用 9.5–10px；好处是不用「更多」菜单——那会变成第二个面。

D2 归档和导入算不算“换页”

推荐：归档是同一份列表的范围条（?scope=archived），不换页；导入是选 agent 的动作菜单，选完留在列表页。只有例行任务、Agent 运维、设置整页推出。

代价：归档没有独立的“页面标题”，靠范围条说明；好处是列表始终只有一份，搜索也始终只有一个。

D3 删掉 dock 和左上角身份圆盘，保留右下新建

推荐：dock 与身份圆盘一起删；新建保留右下浮动按钮。列表页的搜索占满页头，不再给圆盘留位置。

代价：没有常驻的「例行任务」tab，去例行任务要经底部入口；换来的是手机只剩一个导航面，新建仍是最大、最顺手的动作。

D4 返回怎么走

已定（NAVIGATION R2/R3）：页头返回、系统返回、左缘右滑是同一个动作，一步回到列表；深链冷启动合成列表父级。左缘右滑不再开任何抽屉。

代价：原来靠侧滑开抽屉的人要改用底部入口；换来的是手势含义唯一，返回不会走错。
