01 · 手机 · 390×844

HTML 预览：出口始终在 Kin 外层

Figma 帧

用户流程

  1. 起点从文件列表点 HTML，或打开 /tasks/:id?panel=files&file=…。
  2. 动作看预览、切源码、刷新；点「文件」回列表，点「对话」关闭整个面板。
  3. 立刻看到两个文字出口和预览/源码触达都 ≥44px；文件名与视图明确；网页只在内部滚动。
  4. 慢 / 空 / 失败 / 断线顶部返回不随加载消失；失败可读并有新增重试按钮；按 truncated 判断，不冒充完整网页；断线保留已读内容。
  5. 键盘与焦点进入聚焦返回；回列表恢复原行，关闭回文件入口，冷启动回 Files 按钮；iframe 无 Kin 凭据、脚本或任何导航能力。
  6. 离开再回来刷新同 URL 再读 source 文件；关闭清 file/panel；普通打开 Files 不重放旧选择；视图切换不写历史。
02 · 手机 · 390×844

diff：先回文件，再回对话

Figma 帧

用户流程

  1. 起点文件列表或 Changes 的某个 diff，机器/generation 已确定。
  2. 动作阅读增删；宽代码内部横滑；点「文件」回原列表，或「对话」退出面板。
  3. 立刻看到外层标题与两个返回稳定；新增/删除不依赖颜色单独表达。
  4. 慢 / 空 / 失败 / 断线diff 加载或失败时仍能返回；无差异明确说无变化，不给空白；原请求失败不清空对话。
  5. 键盘与焦点回列表焦点/滚动归原 diff 行；系统返回先详情后列表，不绕环、不越过对话离开应用。
  6. 离开再回来generation/diff 用同 URL 临时 history state 支持 Back/Forward，不生成 source URL；刷新只回列表；换 generation 取消旧读取。
03 · Mac · 1100×760

Mac：文件列表与受限 HTML 双栏

Figma 帧

用户流程

  1. 起点同一段对话的 Files，或 Mac 上打开文件深链。
  2. 动作左栏选文件，右栏预览/源码/刷新；关闭回对话。
  3. 立刻看到双栏保留，不套手机页面栈；选中行、文件名和 URL 一致。
  4. 慢 / 空 / 失败 / 断线列表仍在，文件错误只在右栏；关闭不依赖加载成功。
  5. 键盘与焦点文件树和切换可 Tab；关闭后焦点回原 Files 按钮，冷启动回消息流；隐藏 keep-alive pane 不读 URL/抢快捷键。
  6. 离开再回来同 URL 可恢复 source 选中文件；无 panel 的普通对话不暗开面板。

状态

3 张主帧描述稳定布局，六类状态共用同一外层，不另造导航。

加载文件区显示读取中，返回始终可用，不把旧文件标成新文件。
空HTML 空文件显示「没有可预览的内容」，仍可看源码和返回。
失败 / 无权限 / 越界说明读取失败原因，给重试与返回；绝对路径、..、URI 协议不作为文件定位。
断线保留已读内容；重新请求才报离线；回对话不依赖远端成功。
截断 / 缺资源现有读取 truncated=true 不渲染成功页；相对/外链资源不代取，提示预览受限并可看源码。
不可信 HTMLsrcdoc 前用 allowlist 移除 a/base/meta refresh/script；只保留校验后的 data 图片、无 url/import 的 inline CSS；sandbox + CSP。

要你拍板的

D0 修复范围与两个返回

已定：只改现有文件工作区；手机详情回「文件」，外层回「对话」，至少 44px；Mac 保持双栏。

原因：直接对应你报告的问题，不把整套四区重构混进这次修复。

D1 HTML 预览的安全与完整度

推荐：默认预览静态 HTML；内嵌 CSS / data 图片可看，禁脚本、外链网络、表单与导航，始终可切源码。

代价：只承诺自包含 HTML；相对/远程资源不取，a/meta refresh 被移除；data 图片逐项校验，CSS 禁 url/import，因此 CSS 图像本版不显示。换取无新接口或导航权限。

D2 文件深链与系统返回

推荐：/tasks/:id?panel=files&file=相对路径 只定位 source；详情 → 列表 → 对话逐级返回；冷启动插入真实父级，Forward 可恢复，OIDC 保留完整查询。

代价：generation/diff 深链延期；本机绝对路径不跨设备乱读；换取不泄露 cwd/token，冷启动/登录/Back 都有确定父级。
