  • 为什么单独一条：封面的问题是「这里发生过什么」，不是「那段对话在哪」；它有自己的加载、失败、空、离线和「从这里新建」，放进 CONTINUE 会让那条故事既管列表又管项目。
  • 为什么不并进相邻故事：改名、置顶、归档项目仍在列表行（MANAGE-001）；diff 在 RESULT-001；例行任务的调度在 ROUTINE-001。封面只读它们，不做它们的入口之外的编辑。
  • 设备只是差异：这条覆盖 Mac 和手机；Mac 两列、手机单列，差异写在故事「各面差异」，不按设备拆故事。
  • 不在这一条：项目改名 / 置顶 / 归档 → MANAGE-001；di​ff 与分享 → RESULT-001；新建或编辑例行调度 → ROUTINE-001；跨设备同步项目记录 → 暂不在任何故事。

现在 → 之后

现在

  • 封面已经存在，但没有故事、没有页面测试；概览与对话两个 tab 的分工没有写下来。
  • pulse 刷新失败时整页只剩骨架，连「对话」tab 也被挡住。

之后

  • 切到「对话」，行形与列表一致；继续或从这里新建，返回仍在原 tab。
  • 多 root 项目在新建页选目录，不在封面上堆选择器。
  • 例行任务在封面只显示归属和入口，调度仍归 /routines。

01 · Mac · 1100×760

项目封面 · 概览

Figma 帧

用户流程

  1. 起点在 Mac 左栏点项目标题（不是它前面的折叠箭头）；左栏的搜索与折叠保持原样。
  2. 动作读概览：一句话摘要、最近活动、两张热力图；或点「编辑」改摘要、「新建对话」。
  3. 立刻看到页头是项目名、第一个 root、模式；概览先出内容，不在 0.2 秒内闪成全屏骨架。
  4. 慢 / 空 / 失败 / 断线第一次加载出骨架；空项目写「这里还没有对话」；pulse 失败只在概览区给「概览暂时读不到 · 刷新」，对话 tab 仍可用；离线显示上次内容与时间。
  5. 键盘与焦点Tab 能到项目名、两个 tab、编辑与新建；←/→ 换 tab；Esc 回到左栏原来的项目标题。
  6. 离开再回来回到同一 tab 与滚动位置；已保存的摘要保留，未保存的草稿离开前提示。
02 · Mac · 1100×760

项目封面 · 对话

Figma 帧

用户流程

  1. 起点封面概览，点「对话」tab；URL 变成 ?tab=chats，可以直接分享或刷新。
  2. 动作看这个项目的对话；点一行继续，或点「新建对话」。
  3. 立刻看到行上有标题、agent、相对时间、可操作的状态点（运行中 / 等待批准 / 失败）；导入会话与原生对话同形。
  4. 慢 / 空 / 失败 / 断线加载出骨架；没有对话写「这里还没有对话」并给新建；失败给原因与重试，不显示成空；离线时新建禁用，已有对话可读缓存。
  5. 键盘与焦点↑/↓ 换行，Enter 打开，Esc 回概览；行高在手机上至少 44px。
  6. 离开再回来从对话返回，回到对话 tab 与原来的滚动位置，不跳回概览。
03 · 手机 · 390×844

手机 · 项目概览

Figma 帧

用户流程

  1. 起点手机对话列表，点项目标题；返回箭头在左上，至少 44px。
  2. 动作上下滑读概览；点分段控件换到「对话」；点底部「新建对话」。
  3. 立刻看到页头两行放项目名与 root；分段控件有选中态；热力图在卡片内横向滚动，不撑破页面。
  4. 慢 / 空 / 失败 / 断线加载骨架；空与失败文案同 Mac；离线时新建禁用并说明，摘要与热力图显示上次内容。
  5. 键盘与焦点外接键盘：Tab 到分段控件与编辑，分段可用 ←/→；读屏把卡片标题读成 heading。
  6. 离开再回来返回列表后点回同一项目，仍在之前的 tab 与位置。
04 · 手机 · 390×844

手机 · 项目对话

Figma 帧

用户流程

  1. 起点手机项目概览，点「对话」；或从列表直接进来后切 tab。
  2. 动作点一行继续，或点底部「新建对话」。
  3. 立刻看到行与手机列表同形；状态点只给运行中 / 等待批准 / 失败；底部按钮固定，不被列表遮住。
  4. 慢 / 空 / 失败 / 断线骨架；空写「这里还没有对话」；失败给原因与重试；离线时新建禁用。
  5. 键盘与焦点行高 44px 以上；返回后焦点回到进来时的那一行。
  6. 离开再回来返回仍在对话 tab；切到别的项目再回来，tab 与位置都还在。

状态

状态也是 Figma 帧的一部分；先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

空「这里还没有对话」，给「从这里新建」；不排一排 0。
加载骨架只给第一次加载；有缓存时保留内容并标「更新中」。
失败概览失败只影响概览区，给原因与刷新；对话加载失败给原因与重试。
断线顶部标「离线 · 显示上次结果（时间）」；新建与编辑禁用，已有内容可读。
锁定 / 禁用没有 root、离线、没有可用 agent 时，新建按钮禁用并写原因。
编辑中 / 冲突摘要保存显示「保存中 → 已保存」；冲突显示对方版本与两个选择，不静默覆盖。
项目不存在「这个项目不在了」+「回到列表」，不显示空封面。
例行任务不一致封面只显示归属；与机器上的不一致时以 /routines 为准，封面不提供编辑。

要你拍板的

每条都写推荐和代价；只回不同意的编号就行。已经拍过板的写「已定」，不再重复问。

D1 项目从哪里进入

已定：对话列表的项目标题进入 /projects/:id；折叠是它前面的箭头；/projects 索引页已删（R0b-2d，2026-11-10）。

代价：没有「全部项目」一页；项目只能在列表里按设备找。

D2 这条归「整理」还是「接着问」

推荐：归「整理对话与项目」：封面是项目的容器页，回答「这里发生过什么」，与 MANAGE-001 一起把「整理」扩到项目和对话两级。

代价：「整理」故事变成两条；如果更想把它算作「接着问」的入口，CONTINUE-001 会多出一整套项目加载与空状态。

D3 项目页上的例行任务块

推荐：保留为只读归属（项目名 + 下一次时间 + 去 /routines 的入口），不在封面新建或编辑调度。

代价：这块是 Hub 侧遗留，可能与机器上的实际 routines 不一致；彻底收掉会少一个发现入口。

D4 多 root 项目的「新建对话」

推荐：一个 root 时直接带；多个 root 时跳到新建页的设备 / 项目选择（KIN-START-001 的第 3 步），在那一层选目录。

代价：多 root 项目多一步；好处是封面不堆选择器，也不会默认落错目录。
