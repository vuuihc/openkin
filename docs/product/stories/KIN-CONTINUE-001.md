# KIN-CONTINUE-001 · 接着问一段对话

状态：draft
优先级：P0
旅程：J1、J2
归属面：`IA.md`「Mac 上接着问」「手机上接着问」
面：Mac、手机
分轮：4

## 谁、什么时候、为什么

当我上午让 Kin 改的那件事还没问完，我想在 Mac 或手机上找回那段对话，看清它跑到哪了，再发一条往下问，必要时换模型或放宽权限，以便不用从头再讲一遍。

"接着问"就是**打开一段已有的对话，发下一条消息**，不是发一条内容叫"继续"的消息。

## 现在

Mac：左边一列和右边主区各有一份同样的对话列表，各有自己的搜索；⌘K 里还有第三份（`/tasks` 表格），只能从 ⌘K 进。同一个词要在不同地方各输一次。

手机：列表只有"项目 → 对话"两层，同一台机器上的对话和别的设备混在一起；点左上角 K 打开的面板里又是一份列表和搜索。

运行设置：Mac 点"权限"弹出 iPhone 式底部面板（`17-permission-desktop-1280.png`）；点"模型"是 288px 两行的浮层，没有换 agent 的入口。手机把 agent / 模型 / 权限收在输入框底栏的一个入口后面（`RunConfigSheet`），入口的形态是对的，但每行点开是**内嵌展开**，整张面板会跟着变高，选项把下面的行推走。

切换：从列表打开对话、或在对话之间切换时，整个对话区先变成骨架屏，外壳也跟着重绘，出现一次整页白屏。

截图：`03-sessions-1280.png`、`04-search-1280.png`、`18-tasks-1280.png`、`01-sessions-390.png`、`02-drawer-390.png`、`10-search-390.png`、`17-permission-desktop-1280.png`。

## 范围

- 做：找到 → 打开 → 看清状态 → 发下一条 → 改模型/权限 → 回答批准 → 看改动 → 离开。Mac 和手机都要成立。
- 不做：新建对话（`KIN-START-001`）；改名/置顶/删除；产物和分享（Phase 2）。

## 每一步的预期

### 1. 定义 / 打开：我有一段没问完的对话

| 项 | 预期 |
|---|---|
| 起点 | Mac 窗口已开；或手机浏览器/桌面壳打开 |
| 动作 | 打开应用，不点任何东西 |
| 立刻看到 | 上次停留的对话直接打开（Mac 主区、手机对话页），列表在旁边或上一级 |
| 慢 / 空 / 失败 / 断线 | 列表先出骨架；一条对话都没有时说"还没有对话"并给"新建"；断线时顶部一条"连接断开，正在重试"，不清空已加载的列表 |
| 键盘与焦点 | Mac 焦点在输入框，可以直接打字；手机不自动弹键盘 |
| 离开再回来 | 回到上次那段对话，滚动位置不变 |

### 2. 定位：找到上周那段

| 项 | 预期 |
|---|---|
| 起点 | 任意列表 |
| 动作 | 输入关键词；或按 设备 → 项目 逐层找 |
| 立刻看到 | 结果按 设备 → 项目 → 对话 分组出现，匹配的字高亮；设备名一直显示，只有一台设备也不收起 |
| 慢 / 空 / 失败 / 断线 | 输入即搜，200ms 防抖；无结果说"没有匹配的对话"并保留输入；搜索失败说失败原因，不清空结果 |
| 键盘与焦点 | Mac：⌘F 或点搜索框进入，↑/↓ 在结果间移动，Enter 打开，Esc 清空并退出搜索；手机：点搜索框，键盘弹出，取消回到列表 |
| 离开再回来 | 搜索词和滚动位置保留，直到手动清空 |

### 3. 准备 / 确认：看清它跑到哪了

| 项 | 预期 |
|---|---|
| 起点 | 列表里的一条对话 |
| 动作 | 点开 |
| 立刻看到 | 对话占满主区：标题、最后一条消息、当前状态（在跑 / 等你批准 / 已完成 / 失败） |
| 慢 / 空 / 失败 / 断线 | 历史加载中显示骨架；加载失败给重试；对话在跑时底部显示"正在运行"和停止按钮 |
| 键盘与焦点 | 打开后焦点在输入框；Mac 上 Esc 回到列表搜索框；手机返回手势回到列表 |
| 离开再回来 | 回到列表时这条对话的标题和状态已更新 |

### 4. 执行：发下一条

| 项 | 预期 |
|---|---|
| 起点 | 对话页，上一轮已结束或在跑 |
| 动作 | 写一句话，发送（Mac ⌘Enter / 手机发送键） |
| 立刻看到 | 消息立刻出现在流里；后面跟一条排队或运行中的占位；输入框清空并保持焦点 |
| 慢 / 空 / 失败 / 断线 | 空内容不能发；发送失败时消息留在输入框并说明原因；断线时进入本地队列，重连后自动发出，队列可见 |
| 键盘与焦点 | 发送后焦点不回列表；手机键盘不收起（除非用户手动） |
| 离开再回来 | 离开再回来能看到这条消息和它的结果；草稿按对话保存，切走再切回还在 |

### 5. 修改：换 agent、模型或权限

| 项 | 预期 |
|---|---|
| 起点 | 对话页，输入框附近显示当前的 agent、模型和权限 |
| 动作 | Mac 点 agent、模型或权限 chip；手机点输入框底栏的运行设置入口，再点其中一行 |
| 立刻看到 | 两面同一个形态：选项**贴着触发它的控件外弹**，盖在内容上，不内嵌展开。Mac 是贴按钮的浮层（agent 一行一个头像和名字；模型带分组、目录和搜索；权限三项各带一句后果说明，当前项打勾，YOLO 用警示色）。手机是盖在运行设置面板上的第二层，面板本身高度不变，下面的行不被推走 |
| 慢 / 空 / 失败 / 断线 | 下拉数据没到时显示当前值和"加载中"，不显示空列表；保存失败时恢复旧值并提示；当前会话不允许换 agent 时该行是只读的值，不是禁用按钮 |
| 键盘与焦点 | Mac：↑/↓ 移动，Enter 选择，Esc 关闭且焦点回到 chip，不调用 `onChange`；手机：点外面或返回关闭第二层、面板还在，再返回关闭面板；选完焦点回到那一行 |
| 离开再回来 | chip 和底栏显示新值；正在跑的那一轮不受影响（沿用现在的行为，不在这条里改） |

### 6. 监控 / 确认：回答批准

| 项 | 预期 |
|---|---|
| 起点 | 对话里有等待批准的卡片 |
| 动作 | 点"批准"或"拒绝" |
| 立刻看到 | 卡片就地变成结果（谁批的、什么时候），对话继续跑或说明被拒绝后的状态 |
| 慢 / 空 / 失败 / 断线 | 点下去立刻禁用按钮并显示提交中；失败时恢复按钮并说明原因，不假装已批准 |
| 键盘与焦点 | Mac：Tab 到按钮，Enter 触发；结果出现后焦点留在卡片上 |
| 离开再回来 | 在手机上批过的，Mac 上看到的是同一个结果，不出现第二张待批卡片 |

### 7. 收尾：看改动，然后离开

| 项 | 预期 |
|---|---|
| 起点 | 对话跑完 |
| 动作 | 打开改动面板；看完返回列表 |
| 立刻看到 | 改动按文件列出，点文件看 diff；返回列表时这条对话的状态和摘要已更新 |
| 慢 / 空 / 失败 / 断线 | 没有改动时说"这次没有改文件"；diff 读不到时说明原因，不显示空面板 |
| 键盘与焦点 | 面板盖住对话时，对话的 ⌘F 不抢焦点（`239a2dab` 的规则）；Esc 关闭面板，焦点回到打开它的按钮 |
| 离开再回来 | 列表保持搜索词和滚动位置；对话保持滚动位置 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 左边一列是唯一的对话列表（设备 → 项目 → 对话），设备名一直显示；左栏是一整块，导入、归档、设置等是底部一行图标；搜索只在左栏；⌘K 面板里没有对话表格；agent / 模型 / 权限都是贴 chip 的浮层 | 窗口宽，列表和对话可以并排；Mac 上不该出现手机式底部面板 |
| 手机 | 列表页是唯一的对话列表（设备 → 项目 → 对话），设备名一直显示，点进对话后列表退到上一级；K 面板只有入口（新建、导入、收件箱、归档、产物库、例行任务、Agent 运维、设置）；运行设置是底部面板，选项是盖在面板上的第二层，面板高度不变 | 一屏只能放一件事；底部面板是触屏的正确形态，但选择器不许把它撑高 |
| 两面 | 切换对话时外壳不动，只有对话区局部更新；骨架屏只在第一次加载时出现 | 整页重绘会闪白，位置也丢了 |

## 设计

草图：`KIN-CONTINUE-001.review.html`（自包含单页，`open` 即可读）。

必须画到的状态：默认、空、加载、失败、断线、锁定、运行中、等待批准。

## Do not

- Mac 上不许出现 `IonActionSheet`、遮罩、"取消"按钮式的底部面板。
- 不许保留任何第二份对话列表或第二个列表搜索框（Mac 主区、⌘K、手机 K 面板都算）。
- 不新增权限模式；不改存储键 `kin_permission_mode`；不改接口取值。
- 手机上的运行设置面板形态不改，只改里面的选择器：不许内嵌展开撑高面板。
- 不许用原生 `<select>` 承载运行设置；不许把 agent、模型、权限塞回输入框上方的一排 chip。
- 单设备也不许隐藏设备名。
- 切换对话时不许整页变骨架屏或白屏；外壳和已加载内容不许重绘。
- 锁定状态下不许把权限控件藏起来。
- 覆盖层出现时不许继续占用被盖住的面的快捷键。
- 写进对话、推到手机、分享出去的错误文本不许是提供方的 HTML 页面，只能是它自己的话（`fff2c11d`）。
- 不换主题、字体、颜色；不加新功能。
- 不引入新依赖。

## 分轮

- 第 1 轮：Mac 只剩一份列表。删 `/tasks` 路由和它的 ⌘K 入口、`/sessions` 到新建页、⌘K 去掉任务表格、搜索只剩左栏一处；测试 + 1100 截图 + 复审。
- 第 2 轮：手机列表补设备层 + K 面板只留入口 + 归档入口不变；测试 + 390 截图 + 复审。
- 第 3 轮：运行设置。Mac 的 agent / 模型 / 权限都改成贴 chip 的外弹；手机把内嵌展开改成盖在面板上的第二层，高度不变；锁定、键盘、焦点边界；测试 + 两端截图 + 复审。
- 第 4 轮：整条走一遍（打开、切换、发消息、批准、看改动、离开），补空/慢/断线/切换边界和 390/1100 截图。
