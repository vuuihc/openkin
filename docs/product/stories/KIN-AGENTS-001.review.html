01 · Mac · 1100×760

Agent 运维 · 用量与目录

Figma 帧

用户流程

  1. 起点从 Mac 左栏底部或 ⌘K 的「Agent 运维」进入；页面先出标题与用量骨架。
  2. 动作切 7 / 30 / 90 天；扫一眼 agent 表的状态、登录与额度。
  3. 立刻看到四张卡片与每日花费随区间更新；表里默认 agent 有文字标记，未登录 / 未安装 / 需要更新各自有文字。
  4. 慢 / 空 / 失败 / 断线加载骨架；没有用量写「这段时间没有用量」；没有 agent 给安装入口；状态读不到写「状态未知」；离线标时间并禁用动作。
  5. 键盘与焦点表头可点排序并有 aria-sort；Tab 到行尾「⋯」，Enter 打开菜单，Esc 关闭并还焦点。
  6. 离开再回来区间与排序保留；下次打开重新读一次状态，不沿用旧值。
02 · Mac · 1100×760

行内操作与 smoke 结果

Figma 帧

用户流程

  1. 起点目录里一个未登录 / 需要更新的 agent。
  2. 动作点行尾「⋯」，选「重新检查」「smoke 测试」「复制登录命令」或「设为默认」。
  3. 立刻看到那一行就地标「检查中」；完成后状态、时间与默认标记更新；smoke 结果条写清 N 通过 / M 失败 / K 跳过和失败的 agent。
  4. 慢 / 空 / 失败 / 断线动作失败说明哪个 agent、哪一步、下一步；剪贴板失败给「复制失败」；离线时菜单项禁用。
  5. 键盘与焦点菜单里 ↑/↓ 选择，Enter 确认，Esc 关闭并回到行尾按钮；结果条可 Tab 到「关闭」。
  6. 离开再回来已完成的结果保留；进行中的动作离开再回来显示真实状态，不假装完成。
03 · 手机 · 390×844

手机 · 卡片与动作面板

Figma 帧

用户流程

  1. 起点手机 K 面板的「Agent 运维」；页面从头开始。
  2. 动作切区间；点一张 agent 卡片打开动作面板。
  3. 立刻看到卡片一行名字 + 状态，第二行版本 / 登录 / 花费 / 任务；动作面板从底部出现，动作名与 Mac 一致。
  4. 慢 / 空 / 失败 / 断线与 Mac 同样的空、失败、离线文案；动作进行中卡片标「检查中」；面板选完自动关闭。
  5. 键盘与焦点每个动作至少 44px；面板打开时焦点进面板，Esc 或下滑关闭并回卡片。
  6. 离开再回来区间保留；面板不保持；下次打开重新读状态。

状态

状态也是 Figma 帧的一部分；先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

空：没有 agent「还没有可用的 agent」+ 安装入口；新建页也给同一个入口。
空：没有用量「这段时间没有用量」，数字显示「—」，不显示 0。
未登录「需要登录」+「复制登录命令」；不要求用户猜命令。
未安装 / 需要更新「未安装」+「安装」；「0.4.0 → 0.4.2」+「更新」。
额度等待中「等待中 · 12 分钟」+ 进度；恢复后自动可用，不是故障。
检查中那一行标「检查中」，其余行可继续用。
失败smoke 结果条指出失败的 agent 与下一步；不吞原因。
断线「离线 · 显示上次结果（时间）」；动作禁用。
状态未知读不到就说「状态未知」，不猜成可用。

要你拍板的

每条都写推荐和代价；只回不同意的编号就行。已经拍过板的写「已定」，不再重复问。

D1 用量与 agent 目录在同一页

已定：/usage 已重定向到 /agents（2026-11 之前）；用量不再是独立页面，避免第二个「看花了多少」的入口。

代价：只想知道花费的人也要看到 agent 目录；但两件事回答的是同一个问题（环境怎么样）。

D2 「默认 agent」按机器还是按人

推荐：按机器。默认 agent 是这台机器的环境事实（装了什么、登录了什么），换一台机器可以不同。

代价：同一个人在 Mac 和另一台机器上看到的默认可能不同；需要在新建页标出「这台机器的默认」。

D3 重检与 smoke 的范围

推荐：保留「单个 agent」与「全部」两种；全部跑完给结果条，失败点名到 agent。

代价：页头多两个按钮；全部 smoke 可能很慢，需要进度与可取消。

D4 agent 的删除 / 卸载

推荐：这一版不做。删除会动到机器上的安装与凭据，风险与「装/更新」不同级。

代价：装错的 agent 只能去终端卸载；等真实使用需要时另开故事。
