# KIN-RESULT-001 · 看它改了什么

状态：draft
优先级：P1
旅程：J4
归属面：`IA.md`「找产物」
面：Mac、手机

## 谁、什么时候、为什么

当我让 Kin 改完一件事，我想看清它改了哪些文件、每处改成什么、产出了什么，必要时把结果发给别人，以便判断接不接受，而不是只看它说"完成了"。

## 现在

改动在对话流里只是一张摘要卡（`ui/src/components/changedFileFace.tsx`），文件一多就要往上翻；点开 diff 会把对话推走。产物页（`ArtifactsPage`）和对话页各有一套入口，同一个文件两处都能打开。手机上看大 diff 整页重排，返回后位置丢失。

截图：`08-session-1280.png`、`21-session-1100.png`、`15`（手机对话页）。产物页现状不在基线里，交付前补一张。

## 范围

- 做：跑完 → 看这次改了哪些文件 → 打开一个文件的 diff 或产物 → 在文件之间切换 → 回到对话 → 分享或导出 → 离开再回来。
- 不做：编辑文件、回滚、Git 操作（提交、分支、PR）；新建产物；改产物存储。

## 每一步的预期

### 1. 定义 / 打开：它说跑完了，我要看结果

| 项 | 预期 |
|---|---|
| 起点 | 一段刚跑完的对话，Mac 或手机 |
| 动作 | 看对话末尾，不点任何东西 |
| 立刻看到 | 最后一条消息下面是这次的结果摘要：改了 N 个文件（或产出了 N 个产物），以及一个"看改动"入口 |
| 慢 / 空 / 失败 / 断线 | 还在跑时摘要显示"正在运行"而不是 0；这次没有改动时写"这次没有改文件"并说明原因；断线时摘要保留，入口可点但进去是缓存内容 |
| 键盘与焦点 | Mac：Tab 能走到"看改动"；手机：入口在消息末尾，点按区至少 44px |
| 离开再回来 | 这条摘要一直在，不会因为刷新消失 |

### 2. 定位：到底改了哪几个文件

| 项 | 预期 |
|---|---|
| 起点 | 对话页，结果摘要可见 |
| 动作 | 点"看改动" |
| 立刻看到 | 文件列表：路径、+N/−N、状态（新增 / 修改 / 删除）；按目录分组，默认全部展开 |
| 慢 / 空 / 失败 / 断线 | 列表加载中出骨架；加载失败给原因和重试；文件很多时先出前 50 个并说明还有多少 |
| 键盘与焦点 | Mac：↑/↓ 在文件间移动，Enter 打开，Esc 回到对话；手机：列表可滚动，点一行进 diff |
| 离开再回来 | 列表保持滚动位置和已展开的目录 |

### 3. 准备 / 确认：先看摘要，再决定打开哪个

| 项 | 预期 |
|---|---|
| 起点 | 文件列表 |
| 动作 | 悬停或点一个文件，看它的摘要 |
| 立刻看到 | 摘要显示改动的前几行（新增绿、删除红），不打开整页也能判断值不值得看 |
| 慢 / 空 / 失败 / 断线 | 摘要读不到时显示"无法预览"，打开入口仍然可用；二进制文件直接写"二进制文件，无法预览" |
| 键盘与焦点 | Mac：焦点在行上时摘要跟着变，不需要鼠标；手机：点一下进 diff，没有悬停 |
| 离开再回来 | 没有副作用，位置不变 |

### 4. 执行：打开一个文件的 diff

| 项 | 预期 |
|---|---|
| 起点 | 文件列表里的一行 |
| 动作 | 点开 |
| 立刻看到 | 这个文件的 diff：按块显示，行号、增删标记；Mac 在列表右侧，手机占满一屏，顶部一条返回 |
| 慢 / 空 / 失败 / 断线 | 大文件先出骨架再分块渲染；读取失败说原因并给重试；文件在跑完后被删除时说"文件已不存在"，不显示空白 diff |
| 键盘与焦点 | Mac：Esc 回到列表，焦点在刚才那一行；手机：返回手势回列表 |
| 离开再回来 | 回到列表时，打开过的文件有看过标记（同一次会话内） |

### 5. 修改 / 导航：在文件之间接着看

| 项 | 预期 |
|---|---|
| 起点 | 某个文件的 diff |
| 动作 | Mac 按 ↑/↓ 或点下一个文件；手机返回列表再点 |
| 立刻看到 | diff 换成下一个文件，列表里的选中行跟着走；不会退回对话 |
| 慢 / 空 / 失败 / 断线 | 下一个文件加载慢时保留当前 diff，顶部一条细进度；失败时停在当前文件并说明 |
| 键盘与焦点 | Mac：焦点留在 diff 区域内，Read 模式下 PageUp/PageDown 滚动；手机：返回后列表位置不跳 |
| 离开再回来 | 记住最后打开的文件 |

### 6. 监控：大 diff、慢、失败

| 项 | 预期 |
|---|---|
| 起点 | 打开了很大的 diff，或网络不好 |
| 动作 | 滚动、等待 |
| 立刻看到 | 超过阈值的 diff 默认折叠，显示"展开全部"；滚动不卡住整页 |
| 慢 / 空 / 失败 / 断线 | 断线时顶部一条"连接断开，正在重试"，已加载的 diff 不清空；重连后不自动跳位置 |
| 键盘与焦点 | 展开/折叠能用键盘触发，焦点留在按钮上 |
| 离开再回来 | 折叠状态和滚动位置保留 |

### 7. 收尾：分享或导出，然后离开

| 项 | 预期 |
|---|---|
| 起点 | 看完 diff 或产物 |
| 动作 | 点分享或导出；或直接返回对话 |
| 立刻看到 | 分享得到的是这次结果的摘要和文件清单；导出得到文件本身；返回对话时对话停在原来那条消息 |
| 慢 / 空 / 失败 / 断线 | 分享失败说原因，不假装已发；没有产物时分享入口不出现，而不是禁用 |
| 键盘与焦点 | Mac：Esc 关闭分享面板，焦点回到打开它的按钮；手机：系统分享面板关闭后回到原页 |
| 离开再回来 | 回到对话或列表，滚动位置不变；下次再进来还是同一批结果 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 对话右侧一栏：文件列表 + diff 同屏，键盘 ↑/↓ 切换；Esc 回对话 | 窗口宽，列表和 diff 可以并排；键盘是主操作 |
| 手机 | 全屏两级：文件列表 → diff；顶部返回；分享走系统面板 | 一屏只能放一件事；触屏没有悬停 |

## Do not

- 不把 diff 再塞回对话流变成第二份列表；结果只在结果面板里。
- 不引入新的 diff 渲染依赖；用现有组件和样式。
- 不做编辑、回滚、Git 操作。
- 不改产物存储和后端接口。
- 分享不新增第三方服务；沿用现有导出。
- 大 diff 不许卡住整页滚动。
