  • 为什么是独立意图：新建的起点是空的：没有标题、没有历史、没有可复用的上下文。接着问从已有对话开始，项目封面从已有项目开始，三者的空状态和第一屏都不一样。
  • 为什么不并进相邻故事：CONTINUE 不定义空输入与草稿；PROJECT 只回答「这个项目最近发生了什么」；SETTINGS 管默认值，不管这一次选什么；ROUTINE 是到点自己跑，不是现在开始。
  • 设备只是差异：Mac 和手机都是居中的一张输入卡：卡内写提示词、放权限与模型，卡下一条选设备与项目。Mac 的卡更宽、周围留白更多；手机的卡占满宽度，运行设置仍是底部面板。不按设备拆故事。
  • job map 覆盖：定义 / 打开（第 1 步）→ 准备（第 2 步）→ 定位（第 3 步）→ 修改（第 4 步）→ 执行（第 5 步）→ 收尾（第 6 步），六步都有帧和流程。
  • 不在这一条：模板库、推荐提示词（不做）；接着问（CONTINUE）；项目封面的最近活动（PROJECT）；例行任务（ROUTINE）；默认值（SETTINGS）。
  • 大小：5 屏（Mac 新建 / Mac 设备与项目 / 手机新建 / 手机运行设置 / 状态板）；一次交付，两个面都成立。

现在 → 之后

现在

  • Mac 新建页装在一条 576px（max-w-xl）的窄栏里，1280 的窗口空着大半边。
  • 设备、项目、模型、权限挤在输入框下方同一行，四件事互不相干却排在一起。
  • agent、模型、权限散在输入框周围，没有「先写、再选、再开始」的顺序感。

之后

  • Mac 和手机都用一张居中的输入卡：卡内写提示词，底部一行放权限、agent / 模型与「开始」。
  • 「设备 · 项目」是卡下单独一条：先选机器，再选那台机器上的项目；换机器后 agent 列表跟着换。
  • 手机与 Mac 同一构图，只是卡更窄、留白更少；运行设置仍是底部面板，和对话页同一个。
  • 草稿保留到开始或清空；创建失败时留在新建页，提示词不丢。
  • 没有可用 agent、机器离线、断线时，「开始」禁用并就地说明原因。

01 · Mac · 1100×760

Mac · 新建对话（居中输入卡）

Figma 帧

用户流程

  1. 起点Mac 任意页面点左栏顶部「＋ 新建对话」；居中输入卡出现，焦点在提示词，直接可以打字。
  2. 动作写第一句；在卡底一行改权限、agent / 模型；点卡下「本机 · alpha」换机器或项目；点「开始」或按 ⌘Enter。
  3. 立刻看到一屏同时看到提示词、怎么跑、在哪儿跑；卡底一行是权限与「Agent · 模型」，右侧只有一个「开始」；卡下一条显示「机器 · 项目」。
  4. 慢 / 空 / 失败 / 断线机器列表加载时项目条写「正在找机器…」；模型显示当前值 +「加载中」；加载失败给重试且不清空已选；空内容、机器离线、没有可用 agent、断线时「开始」禁用并就地说明。
  5. 键盘与焦点直接可打字；⌘Enter 开始；Tab 顺序是 提示词 → 权限 → agent / 模型 → 开始 → 项目条；Esc 关闭弹层并还焦点。
  6. 离开再回来草稿保留；设备与项目按设备记住上次的项目；权限与模型保留已选值。
02 · Mac · 1100×760

Mac · 选择设备与项目

Figma 帧

用户流程

  1. 起点点输入卡下的「本机 · alpha」这一条；弹层展开，焦点在搜索框。
  2. 动作搜索或 ↑/↓ 选机器，再选那台机器上的项目；也可以输入一个目录；Enter 确认，Esc 关闭。
  3. 立刻看到弹层按机器分组列项目，选中项打勾；这一条变成「机器 / 项目」；下面的 agent 列表跟着设备换。
  4. 慢 / 空 / 失败 / 断线机器列表加载写「正在找机器…」；离线机器标「离线」；机器上没有项目时给「输入目录…」；记住的项目不在了就回到本机并说明，不静默换到别的机器。
  5. 键盘与焦点打开后焦点在搜索框；↑/↓ 选择，Enter 确认，Esc 关闭并把焦点还给这一条。
  6. 离开再回来设备与项目保留，按设备记住上次的项目。
03 · 手机 · 390×844

手机 · 新建对话

Figma 帧

用户流程

  1. 起点手机列表页点主按钮「新建」；全屏居中输入卡出现，不自动弹键盘。
  2. 动作写提示词；点卡底的权限或「Claude Code · 默认模型」打开底部运行设置；点卡下「本机 · alpha」选设备与项目；点「开始」。
  3. 立刻看到一张卡装下提示词与怎么跑，卡下一条是在哪儿跑；「开始」在卡内右下，只有一个；选择器都从底部弹出，不撑高页面。
  4. 慢 / 空 / 失败 / 断线空内容时「开始」禁用；机器离线、没有可用 agent、断线时禁用并说明；创建失败留在本页，提示词不丢。
  5. 键盘与焦点外接键盘 ⌘Enter 开始；键盘不遮挡输入框；关闭面板后焦点回到卡底那一行。
  6. 离开再回来草稿与已选值都还在；开始后进入对话页，新建页不留在历史里。
04 · 手机 · 390×844

手机 · 运行设置

Figma 帧

用户流程

  1. 起点点卡底的权限或「Agent · 模型」；底部面板滑上来，页面本身不跳。
  2. 动作在面板里改 agent、模型、权限；选完自动关闭。
  3. 立刻看到三行同屏，每行是当前值加一句后果；换 agent 后模型列表跟着换。
  4. 慢 / 空 / 失败 / 断线模型加载中显示当前值 +「加载中」；加载失败给重试且不清空；模型不可用时说明原因，不静默回退。
  5. 键盘与焦点外接键盘 ↑/↓ 选择、Enter 确认；Esc 关闭并把焦点还给卡底那一行。
  6. 离开再回来三行保留已选值；草稿还在。

状态

状态也是 Figma 帧的一部分；先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

默认 / 空提示词为空（含只有空白字符）时「开始」禁用；不显示成「正在准备」。
加载机器列表写「正在找机器…」，模型行显示当前值 +「加载中」；骨架只给第一次加载，已有缓存时保留内容。
模型加载失败行内给原因与「重试」；不清空已选，不静默回退到第一个模型。
断线「连接已断 · 恢复后可以开始」；提示词与已选保留；不把它显示成「没有可用 agent」。
没有可用 agent「还没有可用的 agent」+「去 Agent 运维 →」；主按钮禁用。
机器离线选中的机器标「离线」，开始禁用并说明；给一台在线的可切换，不静默换机。
记忆的项目不在了回到本机并说明「上次的项目不在了」；不静默换到别的机器，不清空提示词。
创建失败留在新建页，说明原因并给「重试」；不进入一个空对话，提示词不丢。
草稿 / 开始之后草稿保留到开始或清空；开始后进入对话页，新建页不留在历史里；标题先显示提示词前几个字。

要你拍板的

四条都已按 2026-11-11 的回复定下；这次只需确认重画后的帧与流程，页尾有回复模板。

D1 Mac 新建页用宽布局还是保持窄栏

已定（2026-11-11，按 Codex 方向）：不用左右两栏。改成居中的一张输入卡：卡内写提示词，卡底一行放权限、agent / 模型与「开始」；更大的窗口只让卡周围留白更多，不把控件拉成两列。

代价：卡内一行只放最常用的三项，其余设置仍进运行设置面板；好处是和手机同一构图，写与发的动作留在视线中央。

D2 设备 · 项目放在哪

已定（2026-11-11，按 Codex 方向）：输入卡下面单独一条，点开先选机器、再选那台机器上的项目；不放进输入卡，也不和模型 / 权限同一行。

代价：多一条的高度和一次弹层；换来输入卡保持干净，「在哪儿跑」和「怎么跑」分开，换机器时不会误改模型。

D3 开始之后停在哪

已定（2026-11-11，同意）：立刻进入对话页，第一条已发出并显示「正在运行」；新建页不留在历史里。

代价：首轮失败要在对话页解释与重试；换来输入框马上可用，不用在新建页等结果。

D4 草稿留多久

已定（2026-11-11，同意）：离开保留，直到开始或手动清空；换设备后草稿仍在，但选择按新机器的能力收敛，并说明哪一项变了。

代价：草稿可能过夜，需要一个明确的终点（开始 / 清空）；好处是误触返回不丢内容。
