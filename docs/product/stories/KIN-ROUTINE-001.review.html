  • 为什么是新的意图：前六条都假定「我现在要做一件事」；例行任务的意图是「我不在场时，它按时做」。把调度写进 START-001 会让那条故事同时管一次性的新建和周期调度，两种生命周期、两种空状态。
  • 为什么不并进相邻故事：项目封面只显示例行任务的归属（PROJECT-001），不新建调度；通知只负责把结果送回来（NOTIFY-001），不定义调度；设置管默认 agent 与目录（SETTINGS-001），不管某一台机器上的某一条任务。
  • 为什么属于机器：cwd、agent 凭据、模型与调度都在那台机器上；换一台机器就是另一份列表。Hub 只转发，不持有调度，也不在机器离线时替它跑。
  • 设备只是差异：这条覆盖 Mac 和手机；Mac 列表与运行记录并排、表单就地展开，手机列表与运行记录分屏、表单全屏，差异写在故事「各面差异」，不按设备拆故事。
  • 不在这一条：通知通道与文案 → NOTIFY-001；项目封面上的例行任务块 → PROJECT-001；跨机器的任务总览 → 暂不在任何故事；Hub 侧调度 → 不做；会话本身与在 /routines 里读会话 → 不做（会话在项目里，默认同一条持续）。
  • 大小：5 屏（Mac 列表 / Mac 新建 / 手机列表 / 手机新建 / 状态板）；一次交付；两个面都成立。

现在 → 之后

现在

  • 首次打开落在记住的机器上，即使它已经离线；桌面报 node is not connected，手机停在「Still connecting」。
  • 新建表单里的目录、agent、模型、权限与新建对话不是同一套写法，两处文案会漂移。
  • 「下一次运行」只在服务端算出来，表单里看不到，填错时间要等保存后才知道。
  • 运行记录分页与未读计数没有页面测试；失败原因只在行上出现一次。
  • 跑完的会话落在哪里没有写下来：默认续哪一段、要不要每次新建，都不清楚。

之后

  • 落在第一台在线的非本机机器；记住的机器离线时仍显示它、标「离线」并给切换，不静默换机。
  • 目录 / agent / 模型 / 权限复用新建对话的选择器与文案。
  • 调度旁就地显示「下一次：明天 09:00（本机时区）」；非法调度就地报错并挡住保存。
  • 运行中、成功、失败、等待批准同一行就地变化；未读与侧栏角标同一台机器。
  • 默认同一条会话持续，可选每次执行新建会话；本页只保留运行记录，不内嵌会话。

01 · Mac · 1100×760

例行任务 · 列表与运行记录

Figma 帧

用户流程

  1. 起点Mac 左栏底部点「例行任务」；页面标题旁是一行机器选择，默认落在第一台在线的非本机机器。
  2. 动作扫三行看下一次与上次结果；点一行展开右侧运行记录；点「新建」或行尾的「编辑」。
  3. 立刻看到每行有标题、下一次时间、上次结果、未读；选中行有明显选中态，右侧运行记录按轮次分页，只记时间、结果与耗时；会话在项目里，不在这里展开。
  4. 慢 / 空 / 失败 / 断线机器加载中写「正在找机器…」；记住的机器离线时标「离线」并给一台在线的可切换，新建与 run-now 禁用并说明；读失败给原因与重试，不显示成空。
  5. 键盘与焦点Tab 到机器选择与「新建」；↑/↓ 换行，Enter 展开运行记录，行尾菜单 Esc 关闭并还焦点。
  6. 离开再回来仍停在上次的机器与滚动位置，展开的那一条仍展开。
02 · Mac · 1100×760

Mac · 新建 / 编辑

Figma 帧

用户流程

  1. 起点列表点「新建」，或某一条的「编辑」；表单在列表上方就地展开，列表仍在。
  2. 动作写标题与提示词；选调度（每小时 / 每天 / 每周 / 自定义）、目录、agent、模型、权限、会话方式；读「下一次」后保存。
  3. 立刻看到调度旁立刻显示「本机时区 · 下一次：明天 09:00」；目录 / agent / 模型与新建对话同一套选择器与文案；会话方式默认「同一条会话持续」。
  4. 慢 / 空 / 失败 / 断线目录或模型加载失败给重试且不清空已填；调度非法（过去时间、空规则）就地报错并挡住保存；保存失败留在表单并说明；离线时表单只读。
  5. 键盘与焦点Esc 关闭表单并把焦点还给入口；⌘Enter 保存；表单内 Tab 顺序按视觉顺序。
  6. 离开再回来未保存关闭前提示；重新打开这一条，字段与调度一致。
03 · 手机 · 390×844

手机 · 例行任务

Figma 帧

用户流程

  1. 起点手机 K 面板点「例行任务」；返回箭头在左上，至少 44px。
  2. 动作上下滑列表；点机器名换机器；点一张卡看运行记录；点「立即运行」或「编辑」。
  3. 立刻看到一屏三张卡：标题、下一次、上次结果、未读；失败卡直接给原因，已读卡只给时间。
  4. 慢 / 空 / 失败 / 断线首次加载出骨架；这台机器没有任务写「这台机器还没有例行任务」并给「新建第一条」；离线时新建与 run-now 禁用并说明；读失败给原因与重试。
  5. 键盘与焦点外接键盘 Tab 到机器选择与卡片；点按区至少 44px；读屏把卡标题读成 heading。
  6. 离开再回来返回后仍在同一台机器；再进来停在原来的滚动位置。
04 · 手机 · 390×844

手机 · 新建

Figma 帧

用户流程

  1. 起点手机列表点「新建」；全屏表单从右侧推入，左上关闭，右上保存。
  2. 动作写标题与提示词；点调度打开底部面板选频率与时间；选目录、agent、模型、权限与会话方式；保存。
  3. 立刻看到调度旁就地显示「下一次：明天 09:00（本机时区）」；会话方式默认「同一条会话持续」；选择器选完自动关闭，表单不被撑高。
  4. 慢 / 空 / 失败 / 断线调度非法就地报错并挡住保存；目录加载失败给重试且不清空；保存失败留在表单；离线时只读并说明。
  5. 键盘与焦点保存按钮不被键盘遮住；关闭时若有未保存内容先确认；焦点回到「新建」。
  6. 离开再回来未保存关闭前提示；保存后回到列表，这一条出现在顶部并带下一次时间。

状态

状态也是 Figma 帧的一部分；先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

机器离线仍显示记住的机器并标「离线」，给一台在线的可切换；不静默换机；新建与 run-now 禁用。
空「这台机器还没有例行任务」+「新建第一条」；不排一排 0。
加载骨架只给第一次加载；有缓存时保留内容并标「更新中」。
调度非法过去时间、空规则、不存在的日期就地报错并挡住保存；不静默改成「现在」。
运行中行上显示「运行中…」；离开页面再回来仍是它，不显示成成功。
成功显示时长与改动摘要；未读加一，侧栏角标跟着加。
失败显示原因与「重试」；不显示成已完成；通知没送到不影响这里的结果。
等待批准行上标「等待批准」；点开去那段对话，批准后这一轮继续；通知落到对话，不落到这一页。
未读 / 已读未读与侧栏角标同一台机器；标记失败保留未读并说明；全部标为已读只影响这台机器。
运行记录 / 会话方式运行记录按页加载，旧的接在后面且不重复；它只记时间与结果，不展示会话内容。会话在项目里：默认同一条持续，选了「每次执行新建会话」则每轮开一段新的。

D1 这条算不算第七条意图

已定（2026-11-11）：算。「让它按时跑」是独立意图：前六条都假定人在场、现在要做一件事；这一条是「我不在场时，它按时做」，有自己的页面、状态与生命周期。

代价：故事从六条变七条，PLAN 的意图表要改；如果更想收进「新建对话」，START-001 会同时管一次性新建与周期调度，两种空状态和两种失败都会挤进一条故事。

D2 首次打开落在哪台机器

已定（2026-11-11）：落在第一台在线的非本机机器（没有就落在本机）；记住的机器离线时仍显示它并标「离线」，另给一台在线的可切换。

代价：「非本机」是一个偏好而不是规则；如果读者多数时候只在一台机器上用，这个默认会让人多一步换回本机。

D3 Mac 的新建 / 编辑是就地展开还是单独一页

已定（2026-11-11）：就地展开在列表上方，列表仍在；手机是全屏表单，选择器用底部面板。

代价：Mac 上表单与列表抢纵向空间，窗口矮时表单内滚动；好处是不跳页、保存后立刻在列表里看到这一条。

D4 会话落在哪里

已定（2026-11-11）：不在 /routines 保留会话；本页只留运行记录。定时运行的会话默认在同一条会话里持续；用户可以为每条任务选择「每次执行在对应项目新建会话」。

代价：默认一条会话会越来越长，上下文连续但不容易按轮次回看；每次新建则每轮独立，容易在项目里堆出很多会话。两种都由用户按任务选。
