# KIN-START-001 · 新建一段对话

状态：covered
优先级：P1
旅程：J3
归属面：`IA.md`「新建一段对话」
面：Mac、手机

## 谁、什么时候、为什么

当我想到一件事要交给 Kin，我想在 Mac 或手机上开一段新对话，一屏里决定在哪个项目、用哪个 agent、哪个模型、多大权限，以便马上开始，而不是先翻设置。

## 现在

Mac 新建页把内容装在一条 576px（`max-w-xl`，`ui/src/pages/NewChatPage.tsx:745`）的窄栏里，1280 的窗口空着大半边。device 和项目在输入框下方与模型 / 权限挤在同一行，四件事互不相干却排在一起；agent、模型、权限又散在输入框周围，没有「先写、再选、再开始」的顺序感。

截图：`06-newchat-1280.png`、`13-newchat-390.png`、`14-runconfig-390.png`。

## 范围

- 做：打开新建 → 写提示词 → 选 agent / 模型 / 权限（卡内）→ 选设备与项目（卡下）→ 开始 → 进入对话页。
- 不做：接着问已有对话（`KIN-CONTINUE-001`）；模板库、推荐提示词；例行任务（`KIN-ROUTINE-001`）。

## 每一步的预期

### 1. 定义 / 打开：我要开一段新的

| 项 | 预期 |
|---|---|
| 起点 | Mac 任意页面；或手机列表页 |
| 动作 | 点「新建」（Mac 左栏顶部按钮 / 手机列表页主按钮） |
| 立刻看到 | 新建页；焦点在提示词输入框 |
| 慢 / 空 / 失败 / 断线 | 没有可用 agent 时说「还没有可用的 agent」并给入口；断线时主按钮禁用并说明 |
| 键盘与焦点 | Mac 直接可打字；手机不自动弹键盘 |
| 离开再回来 | 草稿保留（同一段未开始的对话） |

### 2. 准备：写第一句

| 项 | 预期 |
|---|---|
| 起点 | 新建页，空输入框 |
| 动作 | 输入提示词 |
| 立刻看到 | 文本出现在输入框；主按钮从禁用变成可用 |
| 慢 / 空 / 失败 / 断线 | 空内容时主按钮禁用；只有空白字符也算空 |
| 键盘与焦点 | Mac：⌘Enter 开始；手机：发送键开始，键盘不遮挡输入框 |
| 离开再回来 | 内容还在，光标位置不要求 |

### 3. 定位：选设备与项目

| 项 | 预期 |
|---|---|
| 起点 | 新建页；输入卡下面单独一条「设备 · 项目」 |
| 动作 | 点这一条，弹出选择面：先选设备（本机 / 另一台机器），再选那台机器上的项目（工作目录）；也可以输入一个目录 |
| 立刻看到 | 选择面列出设备，每台下面列出它的项目；选中后这一条显示「设备名 · 项目名」；输入卡里的 agent 列表跟着设备换 |
| 慢 / 空 / 失败 / 断线 | 机器列表加载中显示「正在找机器…」；机器离线时该行标「离线」，选中后开始按钮禁用并说明；机器上没有项目时给「输入目录」；记忆的选择已不在时回到本机并说明，不静默换到别的机器 |
| 键盘与焦点 | 打开后焦点在搜索框，↑/↓ 选择，Enter 确认，Esc 关闭并把焦点还给这一条 |
| 离开再回来 | 设备与项目保留（按设备记住上次的项目） |

### 4. 修改：选 agent、模型、权限

| 项 | 预期 |
|---|---|
| 起点 | 新建页，设备与项目已定（或默认本机 + 上次项目） |
| 动作 | Mac 和手机都是卡底一行：权限、agent / 模型；点开是桌面菜单或底部运行设置面板，三行同屏 |
| 立刻看到 | 卡底一行显示当前值和一句后果（模型属于哪个 agent、权限意味着什么）；选了没有的模型时不静默回退，说明原因 |
| 慢 / 空 / 失败 / 断线 | 模型列表加载中显示当前值和「加载中」；加载失败给重试，不清空已选 |
| 键盘与焦点 | Mac：↑/↓ 选择，Enter 确认，Esc 关闭并把焦点还给卡底那一行；手机：选完自动关闭面板 |
| 离开再回来 | 权限与模型保留已选值；换设备后模型 / 权限按那台机器的能力收敛 |

### 5. 执行：开始

| 项 | 预期 |
|---|---|
| 起点 | 有提示词，有可用 agent，设备在线 |
| 动作 | 点「开始」（或 ⌘Enter / 发送键） |
| 立刻看到 | 进入对话页，第一条消息已发出，显示「正在运行」；新建页不再留在历史里 |
| 慢 / 空 / 失败 / 断线 | 创建失败时留在新建页，说明原因，提示词不丢；断线时按钮禁用并说明 |
| 键盘与焦点 | 进入对话页后焦点在输入框，可以继续补话 |
| 离开再回来 | 直接回到这段对话，不会又出现一个空白新建页 |

### 6. 收尾：第一轮已经在跑

| 项 | 预期 |
|---|---|
| 起点 | 刚进入的对话页 |
| 动作 | 等第一轮，或返回列表 |
| 立刻看到 | 标题先显示提示词前几个字，跑完后变成 Kin 生成或用户改过的标题 |
| 慢 / 空 / 失败 / 断线 | 首轮失败时对话页显示失败原因和重试，不显示成「已完成」 |
| 键盘与焦点 | 返回列表后，这条新对话在所属设备、所属项目下、最上面 |
| 离开再回来 | 标题和状态已更新 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 居中一张输入卡（参考 Codex）：卡内写提示词，卡底一行放权限、agent / 模型与「开始」；设备与项目在卡下单独一条；更大的窗口只增加留白，不排成左右两栏 | 写的动作在视线中央；设备 / 项目决定「在哪儿跑」，与卡内「怎么跑」分开；不再把控件拉成两列 |
| 手机 | 同一构图但占满宽度：居中标题 → 输入卡（卡底同样一行）→ 卡下设备 / 项目一条；运行设置是底部面板，和对话页同一个面板 | 一屏只能放一件事；底部面板是触屏的正确形态；与 Mac 保持同一套顺序，不按设备发明第二套布局 |

## 设计

设计稿：`KIN-START-001.review.html`（2026-11-11 签字）。5 屏：Mac 新建（居中输入卡）/ Mac 设备与项目 / 手机新建 / 手机运行设置 / 状态板；帧在 `KIN-START-001.figma/frames/`。

必须画到的状态：默认、空、加载、失败、断线、没有可用 agent、机器离线。

## Do not

- 不新增设置项或权限模式；不改 `kin_permission_mode`。
- 不把设备 / 项目塞进输入卡的控制行，也不放进运行设置面板；它是卡下独立的一条。
- 不再用「左写右选」的左右两栏布局，也不为 Mac 和手机各发明一套顺序。
- 不为新建页另造一套选择器；复用 `KIN-CONTINUE-001` 的桌面菜单和手机的底部面板。
- 不改后端接口。
- 不加模板库、推荐提示词之类的新功能。
- 不在没有可用 agent 或机器离线时让主按钮看起来可点。

## 已知限制

- 「按设备记住上次的项目」只记在这台控制台的浏览器里（`kin_place_projects`）；换一个浏览器或隐私窗口就从草稿本身恢复。已选的 agent 与模型同样记在草稿里（`kin_draft_host` / `kin_draft_model`），换浏览器后回到默认值。
- 机器列表读取失败时不判断「机器不在了」：保留记住的机器、按读失败本身的原因禁用开始，避免把一台只是暂时读不到的机器当成被撤销。
- 输入目录只做形状判断（以 `/`、`~` 或 `.` 开头）；该目录是否存在由那台机器在开始时判断，失败会留在本页并说明。
- 项目 One-Pager 摘要仍在项目条下方显示；签名帧没有画它，但它原本就在这一页，本轮只调整了位置。
