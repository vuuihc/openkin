## 谁、什么时候、为什么

一个人想到一件事要交给 Kin 做，打开应用的第一件事是开一段新对话，并且在一屏里决定用哪个 agent、哪个模型、多大权限。

## 现在

Mac 新建页把内容装在一条 576px（`max-w-xl`，`ui/src/pages/NewChatPage.tsx:745`）的窄栏里，1280 的窗口空着大半边。agent、模型、权限分散在输入框周围，选完一个才能看下一个，没有"这一步在干什么"的顺序感。手机端同样是这几个控件，但走的是底部面板。

截图：`06-newchat-1280.png`、`13-newchat-390.png`、`14-runconfig-390.png`。

## 走完是什么样

1. 打开 → Mac 上新建页用上窗口宽度：左边写提示词，右边一列是 agent / 模型 / 权限，三者在同一屏，主按钮只有一个（"开始"）。
2. 选 → 每一行显示当前值和一句后果（例如模型属于哪个 agent、权限意味着什么），点开是 KIN-MAC-001 里的那些桌面菜单，不是新控件。
3. 手机 → 全屏新建，三步顺序清楚：写 → 选 → 开始；返回不丢已经写的内容。
4. 无法开始 → 没装 agent、断线、项目没有目录时，主按钮禁用并说明原因，不是消失或静默失败。
5. 开始 → 点"开始"进入对话页，第一轮已经在跑，标题先显示提示词前几个字（`acp-session-titles` 的现有行为）。

## Do not

- 不新增设置项或第四种权限模式；不改 `kin_permission_mode`。
- 不为新建页另造一套选择器；复用 KIN-MAC-001 的桌面菜单和手机的底部面板。
- 不改后端接口。
- 不加模板库、推荐提示词之类的新功能。
