# KIN-START-001 · 新建一段对话

状态：draft
优先级：P1
旅程：J3
归属面：`IA.md`「新建一段对话」
面：Mac、手机

## 谁、什么时候、为什么

当我想到一件事要交给 Kin，我想在 Mac 或手机上开一段新对话，一屏里决定用哪个 agent、哪个模型、多大权限，以便马上开始，而不是先翻设置。

## 现在

Mac 新建页把内容装在一条 576px（`max-w-xl`，`ui/src/pages/NewChatPage.tsx:745`）的窄栏里，1280 的窗口空着大半边。agent、模型、权限分散在输入框周围，没有"先写、再选、再开始"的顺序感。

截图：`06-newchat-1280.png`、`13-newchat-390.png`、`14-runconfig-390.png`。

## 范围

- 做：打开新建 → 写提示词 → 选 agent / 模型 / 权限 → 开始 → 进入对话页。
- 不做：接着问已有对话（`KIN-CONTINUE-001`）；模板库、推荐提示词；例行任务。

## 每一步的预期

### 1. 定义 / 打开：我要开一段新的

| 项 | 预期 |
|---|---|
| 起点 | Mac 任意页面；或手机列表页 |
| 动作 | 点"新建"（Mac 左栏顶部按钮 / 手机列表页主按钮） |
| 立刻看到 | 新建页；焦点在提示词输入框 |
| 慢 / 空 / 失败 / 断线 | 没有可用 agent 时说"还没有可用的 agent"并给入口；断线时主按钮禁用并说明 |
| 键盘与焦点 | Mac 直接可打字；手机不自动弹键盘 |
| 离开再回来 | 草稿保留（同一段未开始的对话） |

### 2. 准备：写第一句

| 项 | 预期 |
|---|---|
| 起点 | 新建页，空输入框 |
| 动作 | 输入提示词 |
| 立刻看到 | 文本出现在输入框；主按钮从禁用变成可用 |
| 慢 / 空 / 失败 / 断线 | 空内容时主按钮禁用；只有空白字符也算空 |
| 键盘与焦点 | Mac：⌘Enter 开始；手机：发送键开始，键盘不遮挡输入框 |
| 离开再回来 | 内容还在，光标位置不要求 |

### 3. 修改：选 agent、模型、权限

| 项 | 预期 |
|---|---|
| 起点 | 新建页，运行设置可见 |
| 动作 | Mac：右侧一列三行；手机：底部运行设置面板 |
| 立刻看到 | 每行显示当前值和一句后果（模型属于哪个 agent、权限意味着什么）；选了没有的模型时不静默回退，说明原因 |
| 慢 / 空 / 失败 / 断线 | 模型列表加载中显示当前值和"加载中"；加载失败给重试，不清空已选 |
| 键盘与焦点 | Mac：↑/↓ 选择，Enter 确认，Esc 关闭并把焦点还给那一行；手机：选完自动关闭面板 |
| 离开再回来 | 三行都保留已选值 |

### 4. 执行：开始

| 项 | 预期 |
|---|---|
| 起点 | 有提示词，有可用 agent |
| 动作 | 点"开始"（或 ⌘Enter / 发送键） |
| 立刻看到 | 进入对话页，第一条消息已发出，显示"正在运行"；新建页不再留在历史里 |
| 慢 / 空 / 失败 / 断线 | 创建失败时留在新建页，说明原因，提示词不丢；断线时按钮禁用并说明 |
| 键盘与焦点 | 进入对话页后焦点在输入框，可以继续补话 |
| 离开再回来 | 直接回到这段对话，不会又出现一个空白新建页 |

### 5. 收尾：第一轮已经在跑

| 项 | 预期 |
|---|---|
| 起点 | 刚进入的对话页 |
| 动作 | 等第一轮，或返回列表 |
| 立刻看到 | 标题先显示提示词前几个字，跑完后变成 Kin 生成或用户改过的标题 |
| 慢 / 空 / 失败 / 断线 | 首轮失败时对话页显示失败原因和重试，不显示成"已完成" |
| 键盘与焦点 | 返回列表后，这条新对话在所属项目下、最上面 |
| 离开再回来 | 标题和状态已更新 |

## 各面差异

| 面 | 这一面怎么呈现 | 为什么不同 |
|---|---|---|
| Mac | 用上窗口宽度：左边写提示词，右边一列是 agent / 模型 / 权限，三者同屏；主按钮只有一个"开始" | 窗口宽，没必要挤在 576px 的窄栏里 |
| 手机 | 全屏，顺序是 写 → 选 → 开始；运行设置是底部面板，和对话页同一个面板 | 一屏只能放一件事；底部面板是触屏的正确形态 |

草图：`KIN-START-001.review.html`（还没画；签字前按 `_REVIEW.html` 补，画 写 → 选 → 开始 三步和 390/1100 两个面）。

必须画到的状态：默认、空、加载、失败、断线、没有可用 agent。

## Do not

- 不新增设置项或权限模式；不改 `kin_permission_mode`。
- 不为新建页另造一套选择器；复用 `KIN-CONTINUE-001` 的桌面菜单和手机的底部面板。
- 不改后端接口。
- 不加模板库、推荐提示词之类的新功能。
- 不在没有可用 agent 时让主按钮看起来可点。
