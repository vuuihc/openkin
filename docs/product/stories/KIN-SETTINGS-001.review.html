  • Job map 覆盖：第 1 步定义 / 打开＝01、03 的目录；第 2 步定位＝01、03；第 3 步准备 / 确认＝01 的当前值与影响、05 的默认格；第 4 步执行＝02、04 的选择器；第 5 步修改＝02 的测试连接、04 的保存反馈；第 6 步监控＝05 的失败、断线、未保存三格；第 7 步收尾＝01 的默认 agent 摘要与故事第 7 步（返回新建页）。七步都有落点，没有「先做 Mac 再做手机」。

  • 不在这一条：新增 provider 类型、OAuth scope、schema 变更、kin_permission_mode、账号 / 订阅 / 团队、远程与通知两个旧 tab（R0b-3 已删）、运维表本体（AGENTS-001）、新建页的运行配置（START-001）。

目录：六组、当前值摘要、影响一句

Figma 帧

用户流程

  1. 起点Mac 1100 宽，左栏底部图标进入设置；URL 是 /settings，通用选中。
  2. 动作看目录，或按 Tab 进目录再用 ↑/↓ 换组；也可以点一行。
  3. 立刻看到左边六组：通用、Agents、运维、Providers、路由、高级。每组名下一句当前值（跟随系统 / 2 个可用 / gpt-4.1-mini · 使用中 / 自动 / 价格表已载入），运维行标明归 AGENTS-001；右边是通用组的外观三选一。
  4. 慢 / 空 / 失败 / 断线首次加载：只骨架右边首块，目录照常可见；读不到：目录还在，右边给「设置读取失败」和重试（虚线，未交付）；断线：外壳顶部「重连中…」，已加载的摘要不清空。
  5. 键盘与焦点Tab 进目录，↑/↓ 循环换组，Home / End 到两端；换组后焦点落在新组（或运维的返回行）；读屏把组名与 aria-selected 一起读。
  6. 离开再回来URL 的 ?tab= 记住组；返回设置仍是这一组，目录滚动位置不动；摘要显示已保存的值，不显示未保存的草稿。
02 · Mac · 1100×760

一行的选择器、失败行与未保存

Figma 帧

用户流程

  1. 起点Provider 组，OpenAI 使用中；正在编辑它的 Base URL 与默认模型。
  2. 动作点「默认模型」这一行（或聚焦后 Enter）打开选择器；↑/↓ 选一项，Enter 确定。
  3. 立刻看到选择器贴着这一行向下外弹，盖住下面的字段与按钮，页面高度不变；当前项带 ✓；选完这一行的值立刻变，焦点回到这一行。
  4. 慢 / 空 / 失败 / 断线选项加载中写「加载中」；地址没填先给「请先填写 Base URL」；保存失败在这一行下面给红字（图示「保存失败：该地址未返回任何模型」）并恢复旧值；断线时选择器还能开，保存禁用并说明原因（虚线，未交付）。
  5. 键盘与焦点↑/↓ 移动、Enter 确定、Esc 关闭并把焦点还给这一行；打开时焦点进当前项，Tab 不跑到背后的表单。
  6. 离开再回来已保存的值还在；没保存的改动带「未保存」标记，离开设置时被问一次；失败的行不假装成功。
