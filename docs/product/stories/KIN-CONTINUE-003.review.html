用户流程

  1. 起点Mac的对话区，列表与右侧内容同时可见；导入内容也属于这里。
  2. 动作读历史、看来源、继续或离开当前工作。
  3. 立刻看到新主体只更新右侧工作区，侧栏和列表不被替换；返回保留行与原项目入口。
  4. 慢 / 空 / 失败 / 断线历史分段、较早内容和attach各自提供恢复；不把读历史误标为正在执行新任务。
  5. 键盘与焦点Tab/Enter可达历史与继续；IME/快捷键归可见浮座或输入框。
  6. 离开再回来Mac正常历史保留到导入详情的先读步骤；通知和冷启动由安全映射给父级，不混用。

URL、通知与返回：不用猜

打开完整路由与功能映射，为每个旧URL指定归属、默认父级和保留参数。以下是关键不变量。

手机：四个根有 Tab，详情有一个返回

  1. 起点会话 `/sessions`、项目 `/projects`、例程 `/routines`、设置general为根。
  2. 动作从根或跨区封面进详情，一级换区，或用系统返回。
  3. 立刻看到对话tasks、导入会话、项目封面、远程运行、新建和非general设置隐藏Tab；区归属不变。
  4. 慢 / 空 / 失败 / 断线返回与壳一直可离线退出，不依赖一次请求。
  5. 键盘与焦点先关浮层→再问未保存修改→最后退栈；页头、Back、边缘一致。
  6. 离开再回来详情history保存真实入口URL/位置/触发器；冷启动只合成该区的父级，不虚构滚动或焦点。

通知：具体task + 具体审批/问题，不随便选中

  1. 起点通知给 `/tasks/:id?focus=:item` 或旧 `/inbox?focus=:item`，设备可给 `/routines?device=:device`。
  2. 动作点通知，通过现有pending数据将item解析到所属task，保持原值到新落点。
  3. 立刻看到该task里符合ID的审批/问题卡使用已有focused/高亮与滚动，不是其他卡。
  4. 慢 / 空 / 失败 / 断线task可达但pending未到时保持其局部加载；找不到已处理item就解释，不偷选第一张卡。
  5. 键盘与焦点卡片高亮不强制键盘焦点，收到别的设备已处理不重抢；安全URL白名单保留。
  6. 离开再回来原始 target（含 focus/device）与清理后的可见 URL 分开保存，focus 消费后仍从地址移除；同 target 只在当前或在途时去重，同 task 换 item 仍可定位，离开后同 target 可再点。鉴权、pending 与 leave guard 接受前，shell 读清除的高层链接保留内存重试副本，接受后才确认；拒绝草稿离开时留在原页，给明确重试，不自动导航。
项目
`/projects/:id` 紧邻项目根；最近活动含原生/导入；关闭新建回封面，多root让原选择器处理。从项目进对话再回来是同一封面。
远程运行
`/machines/:device/tasks/:id` 原址不变，冷启动父亲为 `/routines?device=<原设备>`，不忘记机器。
旧运维与设置
`/agents`、`/usage` replace到 `/settings?tab=operations`；原 `agents/providers/routing/advanced/general` 不合并、不改名。
无效链接
未知路径或协议去安全对话根；不把focus挂到无关任务，不打开通知里的主机。鉴权完成后只消费同一次落点。

状态检查表

不要求给每个界面硬塞全部状态；要求每个真实可能发生的状态有合适的语言和下一步。

加载 / 空局部首载骨架或状态文字；加载中不冒充空，空态拥有本区真实的下一步，导航一直可用。
失败 / 断线失败提供原因和重试；断线保住已有内容与草稿；断线状态不通过 toast 一闪而过。
Agent 运行 / 等待流式/工具/等待批准继续利用已有对话语言，不与界面加载混写，方向另行由 design/agentic-states.md 的开放问题决定。
弹层 / 焦点 / 触达Esc 与 Back 先关当前层，随后焦点归还；44px 是触屏底线，桌面密度允许更紧凑；键盘 owner 唯一。
刷新 / 同一应用会话应用内切区保现场；完整刷新的恢复由 URL、已保存或现有草稿决定，不承诺把任意瞬时运行状态跨浏览器重启全序列化。
通知的交付与恢复归一化原target独立保留，不与清理focus后的地址混淆；当前/在途精确重复去重，同task不同item仍可点，离开再回来可重放。鉴权成功、pending定位或明确不存在且leave guard接受前，原target保留内存重试；拒绝留在原页，新tap取代旧排队。接受后清空已接受的原生read-clear副本，不虚构新的跨进程协议。
