本页
  • 为什么单独一条：「哪些页面存在」不属于任何一条意图；它决定其余六条各自做到哪、在哪个页面被验收。没有它，每加一个面只需一次普通 PR。
  • 为什么不并进相邻故事：并进去就会变成「顺手删一个页面」，删的依据是那条故事的方便，不是能力有没有搬完。退场表的每一行都点名负责故事，正是为了挡住这种顺手。
  • 设备只是差异：这条覆盖 Mac 与手机；平板 820 是宽度与输入变体，不是第三个注册面。
  • 不在这一条：删除执行（R-delete-pages、R-agent-status）、重做 agents 安装检测（后续 story）、列表密度（parked R-list-scan）、RN 客户端（独立 ADR/phase）。
  • 大小：5 屏 + 契约板 + 状态板；一次交付装得下：四个页面、运行搬家、设置删一个 tab、退场表、路由清单测试。删除一行一条 PR。

  • 15 条路由、约 10 个真页面；例行页同时放清单和倒序运行，同一运行出现两次。
  • 项目的工作说明只存在独立封面页，列表看不到。

之后

  • 4 个页面：列表（运行也是任务行）、任务详情、例行任务、设置。
  • 运行只在列表出现一次，点开就是那次的详情。
  • 只删 agents tab；其它 5 个 tab 与 provider 凭据位置不动。

01 · 手机 · 390×844

列表：设备 → 项目 → 任务（运行也是任务）

Figma 帧

用户流程

  1. 起点打开 Kin 落在任务列表；顶部只有标题、一个主按钮、搜索；项目与设备默认折叠，只展开上次那个项目。例行任务的每次运行就是一条任务行。
  2. 动作点项目标题展开一层，点项目行看工作说明，或直接点一条任务（对话或运行）。
  3. 立刻看到任务在同一个 shell 里打开；运行行带例行任务名与状态；列表留在下面，滚动位置与展开层级不变。
  4. 慢 / 空 / 失败 / 断线首屏行骨架、不整页白；空写「还没有对话」+「新对话」；搜索无结果写清搜索词；离线设备的行不可展开，点一次说明「连不上这台设备」。
  5. 键盘与焦点Tab 先到搜索框；↑↓ 在行间移动，Enter 打开，Esc 清空搜索并留在列表；行本身是整行命中区，状态与计数只是行内标记。
  6. 离开再回来搜索词、筛选、滚动、展开层级都保留；从任务返回落在原行，不回到顶部。
02 · 手机 · 390×844

任务详情：一条 header、正文、一个 composer

Figma 帧

用户流程

  1. 起点从列表点进来，或从通知/深链落到这条任务；正文上方只有一条 44px header。新建对话是同一页的草稿态。
  2. 动作滚动读回答；点「文件 2」打开面板；在 composer 接着问。
  3. 立刻看到面板在同一条任务上打开，地址不换路由；发出去的消息入流、composer 清空并保持焦点。
  4. 慢 / 空 / 失败 / 断线流式时保留已收到的内容；断线时内容不丢、一条 transient 说明；发送失败草稿留在 composer 并给原因；远端任务离线时同一页说明「这台设备现在连不上」。
  5. 键盘与焦点composer 是唯一输入路径；⌘Enter 发送；Esc 关面板并把焦点还给「文件 2」；返回键第一下只关面板。
  6. 离开再回来草稿、滚动位置、面板开关都按 F4 恢复；不重复发送，不重复弹权限。
03 · 手机 390×844 + Mac 1100×760

例行任务：清单留下，运行搬走

Figma 帧

用户流程

  1. 起点从底部「例行」或 Mac 的区域入口进来；清单写名称、计划、上次运行、启停。
  2. 动作新建或编辑一个例行任务；点某一行的「看运行」。
  3. 立刻看到保存后清单立刻更新；「看运行」跳到任务列表，该例行任务的筛选已就位，每次运行是一条任务行。
  4. 慢 / 空 / 失败 / 断线空写「还没有例行任务」+「新建」；保存失败保留表单并说明；断线时清单可读、保存与启停禁用并说明原因。
  5. 键盘与焦点Tab 按行顺序；Enter 打开编辑；Esc 关闭编辑面板并回到该行；「看运行」也走键盘可达。
  6. 离开再回来回到清单原来的行与滚动位置；从列表返回不会重新创建。
04 · 手机 · 390×844

设置：六个 tab → 五个，只删 agents

Figma 帧

用户流程

  1. 起点从底栏「设置」或列表的 Agents 入口进来（后者落到 operations tab）；默认停在上次的 tab。
  2. 动作在 general / operations / providers / routing / advanced 之间切换；在 providers 里验证或配置凭据。
  3. 立刻看到只有这五个 tab，不再有 agents；保存后新值立刻用于下一次新对话。
  4. 慢 / 空 / 失败 / 断线打开设置不读 secure store、不调第三方；只有「验证/配置」这一次动作才读；失败只说这一行，不影响别的 tab。
  5. 键盘与焦点tab 之间 ←→；关闭确认框回触发按钮；未连接的 provider 行写明原因。
  6. 离开再回来回到上次的 tab；改到一半的 key 输入在离开时清空，不留在内存快照里。
05 · Mac · 1100×760

列表与任务详情：两栏，面板不换路由

Figma 帧

用户流程

  1. 起点从列表打开一条任务；面板默认收起，header 只有「文件 2」与「⋯」两个入口。
  2. 动作点「文件 2」打开面板，选中一个文件，在 diff 行上留评论，点「发回对话」。
  3. 立刻看到面板在主区内展开，对话列变窄但 composer 不动；评论出现在 composer 的待发区，发送后回到对话。
  4. 慢 / 空 / 失败 / 断线diff 读取失败只在面板内说一行加重试；没有改动文件时面板写「这一轮还没有改动」；断线时评论留在本地待发区。
  5. 键盘与焦点Esc 关面板并把焦点还给「文件 2」；Tab 在面板内循环；⌘Enter 发送评论。
  6. 离开再回来面板开关、选中的文件、未发的评论都保留；切到设置再回来不丢。

状态

状态不是新页面：都在同一个 shell 里说一句话。先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

空列表「还没有对话」+ 一个「新对话」；例行任务「还没有例行任务」+「新建」；不铺整页插画，不藏搜索框。
加载只局部：列表行骨架、任务详情保留已读内容；禁止整页骨架（F1：消息不消失）；超过 8 秒补一句「还在读取」。
失败一行原因 + 重试；内容保留；不弹模态、不跳设置页。
断线一条 transient 说明，草稿与待发评论不丢；离线设备的行不可展开，点一次说明原因。
下线能力先在新位置可读，旧路径再下线；退场表写「等哪条故事」；设置 agents tab 先删、重做要有 story。
运行中 / 等待批准状态写在列表行与任务 header 里，不新开页面；approval / question 仍是卡片。
例行运行的失败在列表行上写「失败」，点开是那次运行的详情；例行页不重复一份。

决定（owner 2026-11-22 已定）

D1–D4 按你 11-22 的原话；D5–D6 是同一方向下的实现边界，由 CEO 定、可逆。只有与你说过的不符时才回。

D1 四个页面：列表、任务详情、例行任务、设置

已定：「保留的就是设备-项目-任务列表，任务详情，例行任务列表…设置…这三个页面」。`/routines` 是页面，不改卡片；设置保留。

代价：页面数量不再减少；换来每个页面都能被真机验收到底。

D2 运行列表搬进任务列表

已定：「不包含运行列表，运行列表放到任务列表就行」。例行页只留清单；每次运行是列表里的一条任务行，点开就是那次的详情。

代价：例行页少了一个「顺手看历史」的位置，要多一次跳转；换来同一个运行只出现一次。

D3 设置只删 agents tab，其余保留

已定：「agents 安装检测现在不完备可以删除等重做，其他保留」。删的是安装检测这一块，重做由后续 story 负责；providers 凭据仍留在 providers tab。

代价：暂时没有「装了什么 agent、什么版本」的界面；换来不再展示一个说不准的半成品。

D4 项目不是页面：工作说明进列表的项目行

已定（由 D1 推出）：你的清单里项目只是列表的一层；`/projects` 与 `/projects/:id` 退役，工作说明在项目行展开可读（只读，编辑走「⋯」）。

代价：没有独立的项目封面；换来项目不再是一个半页面，工作说明在打开对话的地方就能读到。

D5 `/new` 是任务详情的草稿态，不是第五个页面

CEO 定：路由保留（已签的 KIN-START-001 与 F1 handoff 依赖它），但归入任务详情这一页；清单测试把它与四个页面分开断言。

代价：页面数说「四个」而路由多一条；换来草稿与详情共用同一个 shell，不丢焦点与草稿。

D6 `/machines/:device/tasks/:id` 合并进 `/tasks/:id?device=`

CEO 定：远端任务与本地任务共用同一份任务详情；RN 端只需要实现一次。

代价：深链必须带对 device；远端离线时要在同一页说明，而不是换一个页面。
