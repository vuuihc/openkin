一句话：当我每天打开 Kin 继续干活，我想只看到五个面——列表、对话、新建、项目封面、设置——其余能力收进对话里的卡片或 sheet，以便每个留下的面都能被真机验收到底，而不是十个页面各好一半。

  3. 最后回决定：D1、D2 已定；D3–D6 各写推荐和代价，页尾有回复模板。

都同意就回「全部同意」；有修改就回「D4 改成…」。宽帧在卡片内左右滑动，页面本身不横滚。

KIN-CONTRACT-001 · 这条
本页
  • 为什么单独一条：「哪些面存在」不属于任何一条意图；它决定其余六条各自做到哪、在哪个面上被验收。没有它，每加一个面只需一次普通 PR。
  • 为什么不并进相邻故事：并进去就会变成「顺手删一个页面」，删的依据是那条故事的方便，不是能力有没有搬完。退场表的每一行都要点名负责故事，正是为了挡住这种顺手。
  • 设备只是差异：这条覆盖 Mac 与手机；平板 820 是宽度与输入变体，不是第三个注册面。差异写在故事「各面差异」，不按设备拆故事。
  • 不在这一条：真正删页面（R-routine-tool、R-provider-sheet、R-usage-surface、R-delete-pages）、RN 客户端（独立 ADR/phase）、列表密度（parked R-list-scan）。
  • 大小：5 屏 + 契约板 + 状态板；一次交付能装下：契约、退场表、路由清单测试。删除按退场表一行一条 PR，不夹带。

01 · 手机 · 390×844

列表：设备 → 项目 → 对话

Figma 帧

用户流程

  1. 起点打开 Kin 落在对话列表；顶部只有标题、一个主按钮、搜索；项目与设备默认折叠，只展开上次那个项目。
  2. 动作点项目标题展开一层，或直接点一段对话的标题。
  3. 立刻看到对话占满主区并在同一个 shell 里打开；列表留在下面，滚动位置与展开层级不变。
  4. 慢 / 空 / 失败 / 断线首屏行骨架、不整页白；空写「还没有对话」+「新对话」；搜索无结果写清搜索词；离线设备的行不可展开，点一次说明「连不上这台设备」。
  5. 键盘与焦点Tab 先到搜索框；↑↓ 在行间移动，Enter 打开，Esc 清空搜索并留在列表；行本身是整行命中区，计数只是行内标记。
  6. 离开再回来搜索词、筛选、滚动、展开层级都保留；从对话返回落在原行，不回到顶部。
02 · 手机 · 390×844

对话：一条 header、正文、一个 composer

Figma 帧

用户流程

  1. 起点从列表点进来，或从通知/深链直接落到这条对话；正文上方只有一条 44px header。
  2. 动作滚动读回答；点「文件 2」打开面板；在 composer 接着问。
  3. 立刻看到面板在同一条对话上打开，地址不换路由；发出去的消息入流、composer 清空并保持焦点。
  4. 慢 / 空 / 失败 / 断线流式时保留已收到的内容；断线时内容不丢、一条 transient 说明；发送失败草稿留在 composer 并给原因。
  5. 键盘与焦点composer 是唯一输入路径；⌘Enter 发送；Esc 关面板并把焦点还给「文件 2」；返回键第一下只关面板。
  6. 离开再回来草稿、滚动位置、面板开关都按 F4 恢复；不重复发送，不重复弹权限。
03 · 手机 · 390×844

设置：只剩 Providers 与 General

Figma 帧

用户流程

  1. 起点从底栏进入设置；默认停在 General（上次看的那一页）。
  2. 动作切到 Providers，点「配置」打开 Provider sheet，或在 General 改默认 agent、模型、权限。
  3. 立刻看到tab 切换只换内容不换面；sheet 从底部升起，关掉回到同一行；保存后新值立刻用于下一次新对话。
  4. 慢 / 空 / 失败 / 断线打开设置不读 secure store、不调第三方；只有「验证 / 配置」这一次动作才读，失败只说这一行失败，不影响其它 provider。
  5. 键盘与焦点tab 之间 ←→；sheet 关闭回触发按钮；未连接的 provider 行写明原因，不是灰掉不说话。
  6. 离开再回来回到上次的 tab；改到一半的 key 输入在 sheet 关闭时清空，不留在内存快照里。
04 · Mac · 1100×760

对话与面板：两栏，面板不换路由

Figma 帧

用户流程

  1. 起点从列表打开一段对话；面板默认收起，header 只有「文件 2」与「⋯」两个入口。
  2. 动作点「文件 2」打开面板，选中一个文件，在 diff 行上留评论，点「发回对话」。
  3. 立刻看到面板在主区内展开，对话列变窄但 composer 不动；评论出现在 composer 的待发区，发送后回到对话。
  4. 慢 / 空 / 失败 / 断线diff 读取失败只在面板内说一行加重试；没有改动文件时面板写「这一轮还没有改动」；断线时评论留在本地待发区。
  5. 键盘与焦点Esc 关面板并把焦点还给「文件 2」；Tab 在面板内循环；⌘Enter 发送评论。
  6. 离开再回来面板开关、选中的文件、未发的评论都保留；切到设置再回来不丢。
05 · Mac · 1100×760

项目封面：保留 /projects/:id，集合页退场

Figma 帧

用户流程

  1. 起点在列表里点项目名的「封面 ›」，或从旧书签 `/projects/:id` 进来。
  2. 动作读工作说明；点「在这个项目里新对话」；要改说明就点「⋯ → 编辑工作说明」。
  3. 立刻看到新对话在同一个 shell 里打开，工作说明已经带上；封面保持只读，不出现第二份可编辑副本。
  4. 慢 / 空 / 失败 / 断线空写「还没有工作说明」+「写一段」；保存失败保留原内容并给重试；断线时封面可读，写入禁用并说明原因。
  5. 键盘与焦点编辑入口在「⋯」；Esc 回「⋯」；保存后焦点回到「⋯」。
  6. 离开再回来滚动位置保留；说明改了以后，下一段新对话用上新值。

状态

状态不是新面：都在同一个 shell 里说一句话。先看状态板，再看下面的检查表。宽板在卡片内左右滑动。

空列表「还没有对话」+ 一个「新对话」；项目封面「还没有工作说明」+「写一段」；不铺整页插画，不藏搜索框。
加载只局部：列表行骨架、对话保留已读内容；禁止整页骨架，F1 要求消息不消失；超过 8 秒补一句「还在读取」。
失败一行原因 + 重试；内容保留；不弹模态、不跳设置页。
断线一条 transient 说明，草稿与待发评论不丢；离线设备的行不可展开，点一次说明原因。
锁定 / 禁用能力还没搬完的旧路径仍可用；退场表写「等哪条故事」；「负责」为空时清单测试不允许删掉它。
运行中 / 等待批准状态写在列表行与对话 header 里，不新开一个面；approval / question 仍是卡片。

要你拍板的

每条都写推荐和代价；只回不同意的编号就行。D1、D2 已定，不用回。

D1 先删后重构，T3 split

已定：先把 UI 面删到最小契约，再用 Expo/RN 重建手机端；桌面保留 Electron + React/Vite，Go daemon 与共享 TS 不重写（ADR 0035，owner 2026-11-21）。

代价：短期内手机端没有新功能，只有变少、变稳；换来 RN 建立时不必照着十个页面重画。

D2 Settings 6 个 tab → 2 个

已定：只留 Providers 与 General；Agent Ops、路由、账号、推送、角色改为对话里的卡片或工具（计划与 `R-provider-sheet`）。

代价：低频设置要多一次「先开对话再用工具」；换来设置不再是一个要单独验收的 App。

D3 文件 / diff / PR 不新增路由

推荐：作为 `/tasks/:id` 内的面板。读与改留在同一条对话里，滚动、草稿、待发评论都不丢；手机上是同一条对话上的面板页，返回第一下只关面板。

代价：深链要带面板参数才能直达某个 diff；390 上打开面板是整屏覆盖，得靠返回把上下文还回来。

D4 `/projects` 集合页退场，保留 `/projects/:id`

推荐：退场。跨项目浏览由列表的设备 → 项目层级与搜索承担；封面保留，因为工作说明是每次新对话都要读的内容。

代价：没有一个「所有项目排成卡片」的总览；换来少一个约 2,691 行的面（计划估算），以及列表成为唯一入口。

D5 `/machines/:device/tasks/:id` 合并进 `/tasks/:id?device=`

推荐：合并。远端任务与本地任务共用同一份阅读面；RN 端只需要实现一次。

代价：一个路由里多一个设备维度，深链必须带对 device；远端离线时要在同一页说明「这台设备现在连不上」，而不是换一个页面。

D6 手机底栏 4 → 2（对话、设置）

推荐：只留两个契约入口，「新对话」移到列表头部的按钮；例行任务与 Agent Ops 从对话里的卡片/工具进入。

代价：去例行任务要多一步（开对话 → 工具）；换来底栏每个入口都是一个被真机验收的面，而不是一个半成品页面。
