01 · 手机 · 390×844

默认：贴底悬浮玻璃 + 四个纯图标

Figma 帧

用户流程

  1. 起点手机上冷启动、从通知或深链进入四个区域中的任意一个。
  2. 动作不点任何东西，先扫一眼底部。
  3. 立刻看到一条贴底悬浮的玻璃条（左右 8px、安全区之上 8px、22px 圆角），内容从下缘隐约透出；四个纯图标等宽；当前区域是实底胶囊 + 着色，其余是线性图标；「对话」右上角若有等待就显示数字。
  4. 慢 / 空 / 失败 / 断线等待数还没读到时不出徽标，不闪 0、不放骨架；断线时底栏本身不变，顶部横幅负责说明；深色或减弱透明下表面变近不透明，布局与图标不变。
  5. 键盘与焦点底栏不自动取焦；进入页面时焦点在内容；Tab 依次经过四个入口；焦点环在玻璃与回退表面上都可见（2px outline + offset）。
  6. 离开再回来仍在同一区域；选中态从 URL 重建，不依赖一次过渡动画；内容滚到底时最后一行能完整滚到玻璃上方至少 12px。
02 · 手机 · 390×844

当前区域 + 等待数：设置被选中，「对话」上还有 3 件

Figma 帧

用户流程

  1. 起点至少 1 件待批准或待回答；当前人在「设置」。
  2. 动作看一眼「对话」图标；要点进去时点整条链接。
  3. 立刻看到「对话」图标右上角一个小计数（1–9，更多显示 9+），不遮挡图标主体；「设置」是实底胶囊 + 着色，其余线性；计数就地更新，不弹 toast。
  4. 慢 / 空 / 失败 / 断线未读到时没有徽标；读失败保留上一次已知计数直到下次成功，不显示 0；断线时保留最后已知计数，不假装清零。
  5. 键盘与焦点徽标不是独立控件，不进 Tab 序；读屏在入口名后播报「3 件在等」；归零时徽标消失，不抢焦点。
  6. 离开再回来计数随 pending 数据刷新，切区域不重置；处理完最后一件事后归零，徽标消失、不留空圈，选中胶囊不变。
03 · 手机 · 390×844

搜索展开 + 键盘：底栏留在键盘后面

Figma 帧

用户流程

  1. 起点对话列表，搜索展开并弹起键盘。
  2. 动作输入「发布」看结果；然后关键盘。
  3. 立刻看到搜索字段与结果贴着键盘上沿；底栏不被顶到键盘上方，留在键盘后面；键盘覆盖底部，底栏不参与键盘布局。
  4. 慢 / 空 / 失败 / 断线键盘动画期间底栏不抖、不重排内容；没有匹配时说「没有匹配的对话」并给「清除搜索」；搜索是本机过滤，断线不影响。
  5. 键盘与焦点展开后焦点在搜索框；Esc 收键盘后焦点回搜索框；键盘弹起时底栏不抢焦，四个入口仍在 Tab 序里。
  6. 离开再回来关键盘后底栏原位回来，搜索词与展开态都不变；切到别的区域再回来，搜索词与展开态仍保留（CONTINUE-004 的行为）。
