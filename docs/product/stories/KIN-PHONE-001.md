# KIN-PHONE-001 · 在手机上找到昨天的对话并接着问

## 谁、什么时候、为什么

一个人在外面，掏出手机想知道昨天那件事跑到哪了。他要一眼看到昨天那段对话，点进去接着问，然后回答 agent 弹出来的批准。

## 现在

手机列表只有"项目 → 对话"两层，同一台 Mac 上的对话和别的设备混在一起。点左上角 K 打开的面板里，又是一份同样的对话列表和一个搜索框，和页面本身重复（`02-drawer-390.png`、`10-search-390.png`）。归档在列表底部单独一段（`11-archive-390.png`）。

## 走完是什么样

1. 打开 → 列表是 设备 → 项目 → 对话 三层。只有一台设备有对话时，设备名收起，直接是项目（和 Mac 左栏同一条规则，`showMachineLabels`）。
2. 找 → 只有一个搜索框，搜出来的结果仍然按 设备 → 项目 分组，不拍平成一条条。
3. K 面板 → 只有入口（新建、设置、设备、归档），没有对话列表，没有第二个搜索框；关掉面板回到原来的滚动位置。
4. 归档 → 一条对话归档后从列表消失，它的项目还在（项目里没有对话时显示空状态）；归档页能看到它。
5. 打开 → 点一条进对话，消息贴底，输入框在键盘上方；发出去之后滚动跟到底。
6. 批准 → 需要批准的卡片出现在消息流里，点"批准"或"拒绝"就地完成，不需要跳到别的页；结果写在卡片上。
7. 边界 → 断线时顶部一条提示，重连后自己恢复；没有对话时列表说清楚下一步是新建。

## Do not

- 不改 Mac 端的列表和控件（属于 KIN-MAC-001）。
- K 面板里不许再出现对话、搜索、项目层级。
- 不新增底部导航栏、标签页或手势。
- 不改批准接口和它的取值。
- 不把归档并进主列表。
