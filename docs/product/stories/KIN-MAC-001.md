# KIN-MAC-001 · 在 Mac 上找到上周的对话并接着问

状态：draft
优先级：P0
旅程：J2
归属面：`IA.md`「Mac 上接着问」
分轮：2

## 谁、什么时候、为什么

一个人坐在 Mac 前，要接着上午没跑完的对话往下问。他需要先找到它，再决定这次用哪个模型、给多大权限，然后看着它改文件。

## 现在

左边一列和右边主区各有一份同样的对话列表，两份各自带搜索；⌘K 里还有第三份（`/tasks` 表格），只能从 ⌘K 进。搜索栏有三个，同一个词要在不同地方各输一次。

点输入框上方的"权限"，弹出来的是 iPhone 那种从底部升上来的面板，盖住大半个窗口，三项一次只能看到一项的说明。点"模型"是一个 288px、两行的浮层，再往里没有目录和分组。

截图：`03-sessions-1280.png`、`04-search-1280.png`、`17-permission-desktop-1280.png`、`09-modelpopover-session-1280.png`、`18-tasks-1280.png`。

## 走完是什么样

1. 打开 → 左边一列是 Mac 上唯一的对话列表：设备 → 项目 → 对话。只有一台设备有对话时，设备名收起（现在左栏已经这样）。右边主区不再有第二份列表：`/sessions` 直接到新建页，`/tasks` 不存在了。
2. 找 → 搜索只有左栏一处，⌘K 仍然能开命令面板，但面板里不再有第三份对话表格。搜"上周那个"能搜到，结果仍按项目分组。
3. 打开 → 点一条，对话占满主区，输入框在底部，焦点在输入框。左栏的搜索词和滚动位置不丢。
4. 改模型 → 点模型 chip，贴按钮向下弹出桌面面板，带目录和分组，↑/↓ 能走、Enter 能选、Esc 关掉并把焦点还给 chip。
5. 改权限 → 点权限 chip，贴按钮向上弹出小菜单：询问 / 自动编辑 / YOLO，各带一句后果说明，当前项打勾，YOLO 用警示色。选完菜单关闭、焦点回到 chip，`onChange` 只触发一次。Esc 和点外面关闭且不改值。锁定时 chip 不可点，锁定提示照常可见。
6. 看 diff → 打开右侧面板，改动按文件列出；面板盖住对话时，对话的 ⌘F 不抢焦点（`239a2dab` 的规则）。
7. 边界 → 没有设备/没有项目时的空状态、加载中、断线重连，各有一句人话；`<768` 宽时按手机处理（见 KIN-PHONE-001），不出现桌面菜单。

## Do not

- Mac 上不许再出现 `IonActionSheet`、遮罩、"取消"按钮式的底部面板。
- 不许保留任何第二份对话列表或第二个列表搜索框。
- 不新增第四种权限模式；不改存储键 `kin_permission_mode`；不改接口取值。
- 不顺手改手机端的面板、位置或文案（那属于 KIN-PHONE-001）。
- 不换主题、字体、颜色；不加新功能。
- 锁定状态下不许把权限控件藏起来。
