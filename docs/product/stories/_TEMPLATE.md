## 走完是什么样

按用户的动作顺序写，一条一步，每步写清结果和边界（空、加载、错误、断线、锁定）：

1. 打开 → 看到什么。
2. 找到 → 怎么找，找不到时什么样。
3. 改 → 改哪里，改完停在哪。
4. 关掉 → 回到哪，焦点在哪。
