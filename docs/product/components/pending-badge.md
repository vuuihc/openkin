# PendingBadge

**行尾的等待标记。** 一个对话有审批或问题在等读者处理时，在自己的行尾报数。
它替代收件箱：徽标不是第二个按钮，整行仍是唯一的点击目标。

## 用它 / 别用它

用它：

- 对话列表的行尾：这一行有几件事在等读者处理（待批审批、待答问题）。
- 手机上底部导航的会话入口：同一个计数压成图标角标，`className` 只负责摆位置。

别用它：

- 可点的“查看待办”入口 → 用 `Button` 或链接。徽标没有点击语义；点它应该和
  点整行一样，那就让整行承担。
- 普通未读数、错误数或任何不是“等你处理”的计数 → 另找控件，不要复用这个
  语义。
- 需要主动播报的状态变化 → 徽标不是 live region；用页面自己的状态消息。

## 行为

- **`count <= 0` 什么都不画。** 返回 `null`，不留空 `<span>`、不占位。
- **可见数字封顶 `9+`，名字带真实数。** 行尾宽度是布局决定；可访问名通过
  `sessions.pendingApprovals` 说出完整句子（英文 “12 waiting for you”，
  中文 “12 项待你处理”）。
- **是 `<span>`，不是按钮。** 没有 `tabIndex`、没有点击处理；对话行或导航项
  是唯一的点击目标。
- **无状态、无副作用。** 不读 store、不发请求、不聚合；`count` 由调用方算好
  传入（`SessionRow` 的 `pendingCount`、`PhoneFooter` 的 `waiting`）。
- **`className` 只做布局。** 尺寸、圆角、底色、字号、字重和 `tabular-nums`
  始终在元素上；`PhoneFooter` 用它把角标绝对定位到图标右上角。
- **名字的来路。** 可见数字是 `aria-hidden`，完整句子在 `sr-only` 文本里。
  容器自己带 `aria-label` 时（`SessionRow` 的整行按钮）行名已经包含这句，
  徽标的文字不参与；容器没有覆盖名称时（`PhoneFooter` 的导航链接），这句
  进入链接名。
- **不播报变化。** 行已经在屏幕上时计数变了，徽标自己不会读出来；需要播报的
  变化归页面或审批层自己的状态消息。

## 键盘

| 键 | 归属 |
|---|---|
| Tab / Shift+Tab | 不在徽标上停留；它不是 Tab 顺序里的停点 |
| Enter / Space | 归所在的对话行或导航链接，不是徽标 |
| 其余按键 | 归当前层；徽标不监听键盘 |

## 无障碍

| 项 | 条款 | 要求 | 状态 |
|---|---|---|---|
| 名称 | 4.1.2 Name, Role, Value | 名字是完整句子（`sessions.pendingApprovals`），不是孤零零的数字 | 全部 |
| 可见数字 | 4.1.2 | 数字 `aria-hidden`，避免和 `sr-only` 句子重复读两遍 | 全部 |
| 对比度 | 1.4.3 Contrast | 橙底 `bg-kin-orange` 配 `text-kin-on-status`，两端都是 token，不替换其中一端 | 全部 |
| 点按区 | 2.5.8 Target Size | 不适用：徽标不是目标；44px 地板由整行（`min-h-11`）或导航项（`min-h-12`）承担 | 手机 |
| 状态播报 | 4.1.3 Status Messages | 徽标不是 live region；行可见时的计数变化不由它播报 | 变化时 |

## 平台差异

| | 手机 | Mac |
|---|---|---|
| 形状 | 18px 高的圆角计数；底部导航里压成图标角标 | 同一个圆角计数 |
| 位置 | 行尾，或图标右上角（`className` 定位） | 对话行尾、时间之前 |
| 点按 | 由整行 / 导航项承担 | 由整行承担 |

## 契约

```ts
type Props = {
  count: number;      // <= 0 时渲染 null
  className?: string; // 只做布局，不替换形状
};
```

不变量：

- `count <= 0` 返回 `null`，不留下空节点或占位。
- 可见文本封顶 `9+`；完整数字只出现在可访问名里。
- 不渲染 `button` / `link` 角色，没有内部状态，没有点击或键盘处理。
- 唯一的文案 key 是 `sessions.pendingApprovals`（`{count}` 插入真实数字），
  不新增自己的 key。
