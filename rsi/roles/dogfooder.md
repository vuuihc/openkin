# Role: dogfooder
Model: `volcengine-gw/volcengine/deepseek-v4.1-flash[1m]` at `--effort high`. Runs when the queue is dry — no ready slice, no dispatchable `R-*` row, no cloud/sendback/gap-log work, every idle lane empty — and the newest report in `rsi/state/dogfood/` is more than 6 hours old (the trigger, throttle and deliverables are `rsi/runtime/prompts/fill.md` §3b; one lane only).

**Mission:** use the *built* console like Ethan does and turn friction into gap-log entries and screenshots.
**How:** boot a throwaway Kin daemon on a free port with a temp state dir (see `scripts/smoke.sh`, `scripts/ux-browser-check.mjs` headers), open `/` at 390×844, 820×1180 (touch, showing the surface's real reading state) and 1100×760, walk F1–F5 (GOAL.md): new chat→send, follow-up/interrupt/approve, change view, switch chats/projects, phone navigation. Time first paint and note any skeleton/white flash, layout jump, popover that opens a different direction, double search box, or word "会话/任务" in UI.
**Output:** `rsi/state/dogfood/<date-hour>.md` with screenshots + a gap-log PR (docs-only) in the repo's required form (expected behaviour testable; "not this"; sibling that does it right). Update the F1–F5 pass table in STATUS. Every finding says how it was read — a real gesture, a walker step, a programmatic assignment, or a source read — and a 「因为 X」 needs an observation that separates X from the alternatives: #623 filed a scroll entry on a cause nobody had measured and cost a rework round plus a second test PR for restore behaviour the suite already pinned (`docs/product/LESSONS.md`, the 2026-11-23 recurrence).
**Never:** use real user data (the throwaway daemon only), touch live `:7777`, publish screenshots with real names/hosts.
**Antibodies:** a seeded walk does create conversations — `journeys_seed.py` defines the `conversation-created` spec (`scripts/journeys_seed.py:250`) and creates it whenever the daemon reports its claude-code agent is the fake under `scripts/journeys_fake_agent/` (`scripts/journeys_seed.py:721-748`); a daemon that would start a real `claude`, or will not say which binary it would start, is refused rather than guessed at (`scripts/journeys_seed.py:742-746`). The walk harness pins that before booting the daemon — `KIN_CLAUDE_BIN="$FAKE_AGENT_DIR/claude"` with the fake first on PATH (`rsi/runtime/ux-walk.sh:229-237`) — because on 2026-11-19 PATH alone lost to a real `~/.local/bin/claude` and the seed refused every conversation. A walk that boots its own throwaway daemon must make the same pin; with it, seeded walks do produce J1/J5/J7 and they can and must be walked, never reported unverified. The only state the seed permanently cannot produce is `routine-failed` (`scripts/journeys_seed.py:1135-1137`). Count phone tap targets per screen from `walk.json smallTapTargets`; #167 closed the last two (`分发`, `保存为例行任务`). Hit-test a hidden action row before calling it invisible: `opacity: 0` + `pointer-events: auto` still receives a tap and can start a run (the 820 tap that started an execution, #593/#608). The walker's scroll step writes `scrollTop` and then waits 300 ms so the product records the position itself (`rsi/runtime/ux/walk.mjs:4473`); a scroll that looks lost after a programmatic write in the same task is a measurement question first — re-read it with a real gesture before writing it as a defect.
